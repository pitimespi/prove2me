# Read-back: `BitcoinSer.serTx_strip`

**Binders and hypothesis.** A single transaction record $tx$ (fields: a natural-number version, a list of inputs each carrying an outpoint, a script, a sequence number and a witness list; a list of outputs each carrying an integer value and a script; a natural-number lock time). No restriction on $tx$: it need not be well-formed, may have no inputs, may have witnesses, may have out-of-range field values. No hypotheses.

**Conclusion.** The witness-free serialization of $tx$ is byte-for-byte the witness-free serialization of its witness-stripped copy:
$$\texttt{serTx}\;\mathrm{false}\;tx = \texttt{serTx}\;\mathrm{false}\;(\texttt{stripWitness}\;tx).$$

**Unfolding.** $\texttt{stripWitness}\;tx$ is $tx$ with every input's witness list replaced by the empty list; all other fields, including the number and order of inputs, are unchanged. $\texttt{serTx}\;aw\;t$ first computes $\phi = 1$ if $aw$ and $\texttt{hasWitness}(t)$ are both true, else $\phi = 0$; then emits $\texttt{ser32}(\texttt{version})$, the two bytes $[0, \phi]$ only if $\phi \ne 0$, the CompactSize-prefixed list of serialized inputs (each input serialized as outpoint hash bytes, 4-byte index, length-prefixed script, 4-byte sequence — never the witness), the CompactSize-prefixed list of serialized outputs, the per-input witness stacks only if $\phi \ne 0$, and finally $\texttt{ser32}(\texttt{nLockTime})$. With the first argument fixed to `false`, $\phi = 0$ on *both* sides regardless of $\texttt{hasWitness}$, so neither side contains the marker bytes or the witness section, and the remaining pieces depend only on version, inputs-without-witness, outputs and lock time, all of which stripping leaves untouched. The statement is therefore that the function $\texttt{serTx}\;\mathrm{false}$ does not look at the witness field at all; both sides are the same expression after substituting $\phi = 0$.

Edge cases silently included: $tx$ with no inputs (both sides begin $\texttt{ser32}(\texttt{version}) \mathbin{+\!\!+} [0] \mathbin{+\!\!+} \dots$); $tx$ already without witnesses (then $\texttt{stripWitness}\;tx = tx$ and the equation is reflexive); field values that the encoders truncate (both sides truncate identically).

**What is not said.** Nothing about $\texttt{serTx}\;\mathrm{true}$: in particular it is *not* claimed that $\texttt{serTx}\;\mathrm{true}\;tx = \texttt{serTx}\;\mathrm{true}\;(\texttt{stripWitness}\;tx)$ (false when $tx$ has a witness, since the left side then carries marker and witness bytes), nor that $\texttt{serTx}\;\mathrm{true}\;(\texttt{stripWitness}\;tx) = \texttt{serTx}\;\mathrm{false}\;tx$ (true by the definitions, but not stated here; compare `weight_no_witness`). Nothing about hashes (that is `txid_strip`), lengths, or parsing. Nothing about well-formedness. It is one equality of byte strings, for all $tx$, with the mode fixed to `false`.
