# Read-back: `Def_BitcoinSig`

**Scope and ambient types.** This file defines, inside a namespace `BitcoinSig`, a collection of total functions and a few predicates over byte strings and transactions. Throughout, a *byte* is an 8-bit vector (so a byte's numeric value is an integer in $[0,255]$) and a *byte string* is a finite list of bytes. Transactions come from the serialization file: a transaction $tx$ has a natural-number field `version`, a list of inputs `vin`, a list of outputs `vout`, and a natural-number field `nLockTime`; an input has a `prevout` (an outpoint: a byte string `hash` and a natural number `n`), a byte string `scriptSig`, a natural number `nSequence`, and a `witness` (list of byte strings); an output has an integer `nValue` and a byte string `scriptPubKey`. None of these fields is bounded by the types: a version or sequence number may be any natural number, an outpoint hash may have any length. Wherever a list is indexed by a possibly out-of-range index, the code uses "get with default", so a *default input* $\langle\langle[],0\rangle,[],0,[]\rangle$ (empty prevout hash, prevout index 0, empty scriptSig, sequence 0, no witness) and a *default output* $\langle -1,[]\rangle$ (value $-1$, empty script) silently stand in. The serializers used are: `ser32` $k$ = the four little-endian bytes of $k \bmod 2^{32}$; `serInt64` $z$ = the eight little-endian bytes of $z \bmod 2^{64}$ (two's complement); `writeCompactSize` $k$ = Bitcoin's compact-size prefix; `serBytes` $b$ = compact size of $|b|$ followed by $b$; `serOutPoint` $o$ = $o.\text{hash}$ followed by `ser32` $o.n$ (so a default outpoint serializes to only four zero bytes, not 36); `serTxOut` $o$ = `serInt64` of the value followed by `serBytes` of the script; `hash256` = SHA-256 applied twice; `leVal` reads a byte string as a little-endian number.

**Constants `p`, `n`, `Gx`, `Gy`.** $p = 2^{256} - 2^{32} - 977$ (a natural number computed by truncated subtraction, which here is an honest subtraction). $n$ is the literal hexadecimal `FFFFFFFF FFFFFFFF FFFFFFFF FFFFFFFE BAAEDCE6 AF48A03B BFD25E8C D0364141`. $G_x$ and $G_y$ are the literal hexadecimals `79BE667E F9DCBBAC 55A06295 CE870B07 029BFCDB 2DCE28D9 59F2815B 16F81798` and `483ADA77 26A3C465 5DA4FBFC 0E1108A8 FD17B448 A6855419 9C47D08F FB10D4B8`. Nothing in the file proves these are prime, that $(G_x,G_y)$ is on the curve, or that $n$ is the order of anything; they are bare numbers.

**`powModAux` and `powMod`.** `powModAux` $m$ is a four-argument recursion on a fuel counter: with fuel $0$ it returns the accumulator; with fuel $f+1$, base $b$, exponent $e$, accumulator $a$: if $e = 0$ it returns $a$; otherwise it recurses with fuel $f$, base $b^2 \bmod m$, exponent $\lfloor e/2 \rfloor$, and accumulator $a\cdot b \bmod m$ if $e$ is odd, else $a$. `powMod` $b\,e\,m$ = `powModAux` $m$ with fuel $e+1$, base $b \bmod m$, exponent $e$, accumulator $1 \bmod m$. Since the exponent halves each step, fuel $e+1$ is never exhausted before $e$ reaches $0$, so this computes $b^e \bmod m$ for $m \geq 1$. For $m = 0$, Lean's $x \bmod 0 = x$, so the function would compute an unreduced power; no caller passes $m=0$.

**`finv` and `ninv`.** `finv` $a$ = `powMod` $a\,(p-2)\,p$, i.e. $a^{p-2} \bmod p$. For $a = 0$ this is $0$ (the accumulator is multiplied by $0$ at the first odd bit, since $p-2$ is odd). `ninv` $a$ = $a^{n-2} \bmod n$, likewise with `ninv` $0 = 0$. No reduction of $a$ is required beforehand; `powMod` reduces the base. These are inverses only when $p$, $n$ are prime and $a \not\equiv 0$; the file does not state this.

**`Point`, `onCurve`.** A point is either "none" (the point at infinity) or "some $(x,y)$" with $x, y$ arbitrary natural numbers, *not* required to be below $p$ or on the curve. `onCurve` $(x,y)$ is the Boolean $y^2 \bmod p = (x^3 + 7) \bmod p$.

**`padd` (affine addition).** For points $P, Q$: if $P$ is none the result is $Q$; if $Q$ is none the result is $P$ (so none $+$ none $=$ none). Otherwise, with $P = (x_1,y_1)$ and $Q = (x_2,y_2)$:
- if $x_1 \equiv x_2 \pmod p$: if $y_1 + y_2 \equiv 0 \pmod p$ the result is none; otherwise the *doubling* formulas are used **with the coordinates of $P$ only**: $\lambda = 3x_1^2 \cdot \mathrm{finv}(2y_1 \bmod p) \bmod p$, $x_3 = (\lambda^2 + 2(p - (x_1 \bmod p))) \bmod p$, $y_3 = (\lambda\,((x_1 + p - x_3) \bmod p) + (p - (y_1 \bmod p))) \bmod p$, result $(x_3,y_3)$. Note the doubling branch is taken whenever the abscissae agree and the ordinates are not negatives mod $p$, even if $y_1 \not\equiv y_2$ (which can only happen for inputs that are not both on the curve); $Q$'s ordinate is then ignored. If $2y_1 \equiv 0$, `finv` returns $0$ and $\lambda = 0$.
- otherwise (distinct abscissae mod $p$): $\lambda = ((y_2 + p - (y_1 \bmod p)) \bmod p)\cdot \mathrm{finv}((x_2 + p - (x_1 \bmod p)) \bmod p) \bmod p$, $x_3 = (\lambda^2 + (p - (x_1 \bmod p)) + (p - (x_2 \bmod p))) \bmod p$, $y_3 = (\lambda\,((x_1 + p - x_3) \bmod p) + (p - (y_1 \bmod p))) \bmod p$.
All outputs have coordinates below $p$; inputs may be unreduced. No on-curve check is performed.

**`pmulAux`, `pmul`, `G`.** `pmulAux` with fuel $0$ returns the accumulator; with fuel $f+1$, scalar $k$, point $P$, accumulator $A$: if $k = 0$ returns $A$, else recurses with fuel $f$, scalar $\lfloor k/2\rfloor$, point `padd` $P\,P$, accumulator `padd` $A\,P$ if $k$ odd else $A$. `pmul` $k\,P$ = `pmulAux` with fuel $257$, scalar $k$, point $P$, accumulator none: right-to-left double-and-add. With fuel 257 any $k < 2^{257}$ is processed completely; for larger $k$ the high bits are silently dropped. $G$ = some $(G_x, G_y)$.

**`beVal`.** The big-endian value of a byte string: fold $a \mapsto 256a + \text{byte}$ from $0$. The empty string has value $0$. No length limit.

**`liftXParity` $x$ *odd*.** Computes $y = (x^3+7)^{(p+1)/4} \bmod p$ (integer division for the exponent). If $y^2 \bmod p = (x^3+7) \bmod p$, returns some $(x, y')$ where $y' = y$ if the parity of $y$ (as a natural number, i.e. $y \bmod 2 = 1$) equals the requested Boolean *odd*, and $y' = (p - y) \bmod p$ otherwise; else returns none. Note $x$ is not reduced or range-checked here, and the returned abscissa is $x$ exactly as given. Edge: if $y = 0$ (i.e. $x^3+7 \equiv 0$) and *odd* is true, the returned ordinate is $(p-0) \bmod p = 0$, which is even.

**`parsePubkey`.** On the empty string: none. On $t :: rest$ (first byte $t$): if the total length is $33$ and $t \in \{2,3\}$, let $x$ = `beVal` $rest$; if $x < p$ return `liftXParity` $x\,(t = 3)$ (odd ordinate exactly when $t = 3$), else none. Else if the total length is $65$ and $t \in \{4,6,7\}$: $x$ = `beVal` of the first 32 bytes of $rest$, $y$ = `beVal` of the remaining 32; return some $(x,y)$ if $x < p$ and $y < p$ and (if $t \in \{6,7\}$ then "$y$ is odd" iff $t = 7$) and `onCurve` $(x,y)$; else none. In every other case (wrong length for the tag, tag outside $\{2,3,4,6,7\}$) none. The tag-$4$ case has no parity requirement.

**`pubkeyLen`, `pubkeyValid`.** `pubkeyLen` $h$ is $33$ for $h \in \{2,3\}$, $65$ for $h \in \{4,6,7\}$, and $0$ otherwise. `pubkeyValid` $pk$ is false on the empty string and otherwise decides whether `pubkeyLen` (first byte) equals the actual length. Since a non-empty string has length $\geq 1 \neq 0$, an unrecognized header always yields false. This is a header/length check only: no curve membership.

**`isHighS`, `normalizeS`.** `isHighS` $s$ decides $\lfloor n/2 \rfloor < s$. `normalizeS` $s$ = $n - s$ (truncated natural subtraction) if `isHighS` $s$, else $s$. For $s \geq n$ (high), $n - s$ truncates to $0$.

**`scalarOf`.** Reads $b$ big-endian; returns some $v$ if $v < n$, else none. **This definition is not used anywhere else in the file.**

**`parseDerLax` (lax DER parser).** Input: a byte string of length $\ell$; `at`$(i)$ denotes the byte at index $i$ or $0$ if out of range. Control flow, in order:
1. If $\ell = 0$ or `at`$(0) \neq$ `0x30`: none.
2. Set $pos = 1$. If $pos = \ell$: none. Read $lenbyte$ = `at`$(1)$; $pos = 2$.
3. Sequence length: if $lenbyte \geq$ `0x80`, let $lb = lenbyte - $ `0x80`; if $\ell - pos < lb$ (natural subtraction; $\ell \geq 2$ here) then none, else $pos = 2 + lb$ — **the $lb$ length bytes are skipped, their value is never read**. If $lenbyte <$ `0x80`, $pos$ stays $2$ and **the short-form length value is ignored entirely**. (Note $lenbyte =$ `0x80` gives $lb = 0$ and is accepted.)
4. `readInt`$(pos)$, used twice: if $pos = \ell$ or `at`$(pos) \neq$ `0x02`: none. $pos{+}{+}$; if $pos = \ell$: none. $lenbyte$ = `at`$(pos)$; $pos{+}{+}$. If $lenbyte \geq$ `0x80`: $lb = lenbyte - $ `0x80`; if $\ell - pos < lb$: none; then skip up to $lb$ leading zero bytes among the length bytes (each skip increments $pos$ and decrements $lb$); if the remaining $lb \geq 4$: none; the integer's length $rlen$ is the big-endian value of the remaining $lb$ bytes (zero if $lb = 0$); $pos$ advances past them; if $\ell - pos < rlen$: none; else return (start $= pos$, length $= rlen$, end $= pos + rlen$). If $lenbyte <$ `0x80`: if $\ell - pos < lenbyte$: none; else return ($pos$, $lenbyte$, $pos + lenbyte$).
5. First `readInt` at $pos$ gives $(rpos, rlen, pos')$ or none $\Rightarrow$ none. Second `readInt` at $pos'$ gives $(spos, slen, \_)$ or none $\Rightarrow$ none; **the end position of the second integer is discarded, so any trailing bytes after $S$ are ignored**.
6. Strip leading zero bytes from each of $R$ and $S$ (advancing the start, shrinking the length, fuel = the length).
7. If the stripped $rlen > 32$ or $slen > 32$: **some $(0,0)$**.
8. $r$ = `beVal` of the $rlen$ bytes at $rpos$, $s$ likewise. If $r < n$ and $s < n$: some $(r,s)$; otherwise **some $(0,0)$**.
So none is returned only for structural failures (tags, lengths running past the end, a length-of-length of 4 or more bytes); a zero-length integer parses as $0$; an all-zero or too-long or $\geq n$ integer yields the pair $(0,0)$, indistinguishable from a signature that genuinely encodes $r = s = 0$.

**`ecdsaVerifyRaw` $Q\,e\,r\,s$.** $Q$ is a point (possibly none), $e, r, s$ natural numbers. If $r = 0$ or $s = 0$ or $r \geq n$ or $s \geq n$: false. Else $w = $ `ninv` $s$, $u_1 = e w \bmod n$, $u_2 = r w \bmod n$, and $R = $ `padd` (`pmul` $u_1\,G$) (`pmul` $u_2\,Q$). If $R$ is none: false; if $R = (x, \_)$: the Boolean $x \bmod n = r$. $e$ is used as given (not reduced here). If $Q$ is none, $R = u_1 G$.

**`pubkeyVerify` $pk\,hash\,sig$.** If not `pubkeyValid` $pk$: false. Else if `parsePubkey` $pk$ is none: false. Else with $Q$ the parsed point: if `parseDerLax` $sig$ is none: false; else with $(r,s)$: `ecdsaVerifyRaw` (some $Q$) (`beVal` $hash \bmod n$) $r$ (`normalizeS` $s$). The message is the **big-endian** value of the byte string $hash$ reduced mod $n$; $hash$ has no length requirement. In particular the constant `uint256One` below, read this way, is $256^{31} = 2^{248}$, not $1$. The $S$ value is always normalized to the low half before verification, so a high-$S$ signature verifies iff its low-$S$ twin does.

**`checkLowS` $sig$.** If `parseDerLax` $sig$ is none: false; else true iff the parsed $s$ is not high. Note that the overflow result $(0,0)$ has $s = 0$, so a signature with an overflowing or over-long $S$ (or $R$) passes `checkLowS`.

**`taggedHash`, `ascii`, `liftX`.** `taggedHash` $tag\,m$ = SHA-256$(h \,\|\, h \,\|\, m)$ with $h$ = SHA-256$(tag)$. `ascii` $s$ = the UTF-8 bytes of the string $s$, each truncated to 8 bits. `liftX` $x$ = `liftXParity` $x$ false (even ordinate) if $x < p$, else none.

**`schnorrVerify` $pk_{32}\,msg\,sig_{64}$.** If $|pk_{32}| \neq 32$ or $|sig_{64}| \neq 64$: false. $r$ = big-endian value of the first 32 bytes of the signature, $s$ = of the last 32. If $r \geq p$ or $s \geq n$: false. $P$ = `liftX`(big-endian $pk_{32}$); none $\Rightarrow$ false. $e$ = big-endian value of `taggedHash`(ascii "BIP0340/challenge") (first 32 signature bytes $\|$ $pk_{32}$ $\|$ $msg$), reduced mod $n$. $R$ = `padd` (`pmul` $s\,G$) (`pmul` $((n - e) \bmod n)$ (some $P$)). If $R$ is none: false; if $R = (r_x, r_y)$: the Boolean ($r_y$ even and $r_x = r$). $msg$ has no length constraint.

**`OP_PUSHDATA1/2/4`.** The numbers `0x4c`, `0x4d`, `0x4e`.

**`getOp` $s$.** On the empty string: none. On $op :: rest$ with $o$ the value of $op$: if $o \leq$ `0x4e`, determine a size and remainder: $o <$ `0x4c` $\Rightarrow$ size $o$, remainder $rest$; $o =$ `0x4c` $\Rightarrow$ size = next byte, remainder after it, none if $rest$ is empty; $o =$ `0x4d` $\Rightarrow$ size = little-endian value of the next 2 bytes, none if fewer than 2; otherwise ($o =$ `0x4e`) size = little-endian value of the next 4 bytes, none if fewer than 4. Then if the remainder is shorter than the size: none; else some (push of the first *size* bytes, the rest). If $o >$ `0x4e`: some (op $op$, $rest$). So byte `0x00` is a push of the empty string.

**`parseScriptAux`, `parseScript`.** `parseScriptAux` with any fuel and empty input: some $[]$. Fuel $0$ and non-empty input: none. Fuel $f+1$: `getOp`; none $\Rightarrow$ none; else parse the remainder with fuel $f$ and prepend the instruction. `parseScript` $s$ = `parseScriptAux` with fuel $|s|$. Since every `getOp` consumes at least one byte, the fuel is sufficient; the result is none exactly when some push runs past the end of the data.

**`pushBytes` $d$.** If $|d| <$ `0x4c`: the byte $|d|$ followed by $d$ (so `pushBytes` $[]$ = $[$`0x00`$]$). Else if $|d| \leq 255$: `0x4c`, byte $|d|$, $d$. Else if $|d| \leq 65535$: `0x4d`, two little-endian length bytes, $d$. Else `0x4e`, four little-endian length bytes, $d$ (length bytes are truncated mod $2^{32}$ for absurdly long $d$).

**`findAndDeleteAux`, `findAndDelete`.** `findAndDelete` $script\,b$: if $b$ is empty, $(script, 0)$; else `findAndDeleteAux` $b$ with fuel $|script| + 1$, remaining $= script$, accumulator $[]$, count $0$. `findAndDeleteAux`: with fuel $0$ returns (accumulator $\|$ remaining, count). With fuel $f+1$: first *strip*: as long as $b$ is a byte-prefix of the remaining string (and $|b| \leq$ remaining length), drop $|b|$ bytes and increment the count (fuel for this inner loop = remaining length $+1$, which suffices). Then `getOp` on what remains: none $\Rightarrow$ (accumulator $\|$ remaining, count) — a malformed tail is appended verbatim; some $(\_, r)$ $\Rightarrow$ the consumed bytes (those before $r$) are appended to the accumulator and the recursion continues on $r$ with fuel $f$. So $b$ is matched as raw bytes at each instruction boundary (including immediately after a previous deletion), not as a parsed instruction. Each round removes or consumes at least one byte, so the outer fuel suffices.

**`scriptCodeBytesAux`, `serScriptCode`.** `scriptCodeBytesAux` with fuel $0$ returns the input unchanged; otherwise `getOp`; none $\Rightarrow$ the input unchanged (malformed tail kept verbatim); some $(i, r)$ $\Rightarrow$ (the consumed bytes, or $[]$ if $i$ is the opcode instruction with byte `0xab`, i.e. `OP_CODESEPARATOR`) $\|$ recursion on $r$. `serScriptCode` $sc$ = compact size of the length of the stripped body, followed by the body (fuel $|sc|+1$).

**`SIGHASH_*` constants and `uint256One`.** `SIGHASH_ALL` $= 1$, `SIGHASH_NONE` $= 2$, `SIGHASH_SINGLE` $= 3$, `SIGHASH_ANYONECANPAY` $= 128$. `uint256One` = the byte $1$ followed by 31 zero bytes.

**`serSigInput` $tx\,scriptCode\,nIn\,acp\,single\,none\,nInput$.** First, if $acp$ then $nInput := nIn$. Let $i$ = the $nInput$-th input of $tx$ or the default input. Output: `serOutPoint` $i.\text{prevout}$ $\|$ (if $nInput \neq nIn$ then `serBytes` $[]$ $= [$`0x00`$]$ else `serScriptCode` $scriptCode$) $\|$ (if $nInput \neq nIn$ and ($single$ or $none$) then `ser32` $0$ else `ser32` $i.\text{nSequence}$). The input's own `scriptSig` and `witness` are never serialized.

**`serSigOutput` $tx\,nIn\,single\,nOutput$.** If $single$ and $nOutput \neq nIn$: `serTxOut` $\langle -1, [] \rangle$ (eight `0xff` bytes then `0x00`); else `serTxOut` of the $nOutput$-th output, or of the default $\langle -1,[]\rangle$ if out of range.

**`serSigTx` $tx\,scriptCode\,nIn\,hashType$.** $acp$ := ($hashType \mathbin{\&} 128 \neq 0$); $single$ := ($hashType \mathbin{\&} 31 = 3$); $none$ := ($hashType \mathbin{\&} 31 = 2$). $nInputs$ = $1$ if $acp$ else $|vin|$. $nOutputs$ = $0$ if $none$, else $nIn + 1$ if $single$, else $|vout|$. Output, in order: `ser32` $tx.\text{version}$ $\|$ compact size $nInputs$ $\|$ concatenation of `serSigInput` for $nInput = 0,\dots,nInputs-1$ $\|$ compact size $nOutputs$ $\|$ concatenation of `serSigOutput` for $nOutput = 0, \dots, nOutputs - 1$ $\|$ `ser32` $tx.\text{nLockTime}$. The hash type is **not** appended here. If $nIn \geq |vin|$ and not $acp$, no input ever receives the script code; if $acp$, the single serialized input is the default input (4-byte outpoint). Hash types whose low five bits are not $2$ or $3$ (e.g. $0$, $1$, or $4$–$31$) all serialize as "all outputs".

**`sigHashLegacy` $scriptCode\,tx\,nIn\,hashType$.** If $hashType \mathbin{\&} 31 = 3$ and $|vout| \leq nIn$: `uint256One`. Otherwise `hash256`(`serSigTx` $tx\,scriptCode\,nIn\,hashType$ $\|$ `ser32` $hashType$). Fields serialized: version; input count; per input: prevout, script code (or empty), sequence (or zero); output count; per output: value and script (or $-1$/empty); lock time; then the 4-byte hash type. $hashType$ is an unbounded natural number here; `ser32` truncates it.

**`sigHashWitnessV0` $scriptCode\,tx\,nIn\,hashType\,amount$.** With $acp$, $single$, $none$ as above and $zero$ = 32 zero bytes: $hashPrevouts$ = `hash256` of the concatenation of `serOutPoint` over **all** inputs if not $acp$, else $zero$. $hashSequence$ = `hash256` of the concatenation of `ser32` of every input's sequence if not $acp$ and not $single$ and not $none$, else $zero$. $hashOutputs$ = `hash256` of the concatenation of `serTxOut` over all outputs if neither $single$ nor $none$; else if $single$ and $nIn < |vout|$ (strict): `hash256`(`serTxOut` of output $nIn$); else $zero$. Let $i$ = input $nIn$ or the default. Result: `hash256`(`ser32` version $\|$ $hashPrevouts$ $\|$ $hashSequence$ $\|$ `serOutPoint` $i.\text{prevout}$ $\|$ `serBytes` $scriptCode$ $\|$ `serInt64` $amount$ $\|$ `ser32` $i.\text{nSequence}$ $\|$ $hashOutputs$ $\|$ `ser32` nLockTime $\|$ `ser32` $hashType$). Here the script code is serialized **verbatim with `serBytes`** (no `OP_CODESEPARATOR` removal, unlike the legacy path), there is no `uint256One` special case, and a negative $amount$ is serialized in two's complement without complaint.

**`isValidSignatureEncoding` $sig$.** With $\ell = |sig|$ and `at` as before: false if $\ell < 9$; false if $\ell > 73$; false if `at`$(0) \neq$ `0x30`; false if `at`$(1) \neq \ell - 3$; let $lenR$ = `at`$(3)$; false if $\ell \leq 5 + lenR$; let $lenS$ = `at`$(5 + lenR)$; false if $lenR + lenS + 7 \neq \ell$; false if `at`$(2) \neq$ `0x02`; false if $lenR = 0$; false if `at`$(4) \geq$ `0x80`; false if $lenR > 1$ and `at`$(4) = 0$ and `at`$(5) <$ `0x80`; false if `at`$(lenR + 4) \neq$ `0x02`; false if $lenS = 0$; false if `at`$(lenR+6) \geq$ `0x80`; false if $lenS > 1$ and `at`$(lenR+6) = 0$ and `at`$(lenR+7) <$ `0x80`; otherwise true. The final byte (hash type) is never examined. Note that the $\ell \leq 73$ bound forces $lenR + lenS \leq 66$.

**`isLowDERSignature` $sig$.** `isValidSignatureEncoding` $sig$ and `checkLowS` ($sig$ with its last byte removed). Both conjuncts are evaluated on the same $sig$ argument; only the second drops the hash-type byte.

**`isCompressedOrUncompressedPubKey` $pk$.** Empty: false. Otherwise with first byte $h$: false if $|pk| < 33$; if $h = 4$: $|pk| = 65$; if $h \in \{2,3\}$: $|pk| = 33$; else false (so hybrid $6$/$7$ keys are rejected here even though `parsePubkey` accepts them).

**`isCompressedPubKey` $pk$.** Non-empty, length $33$, and first byte in $\{2,3\}$.

**`isDefinedHashtypeSignature` $sig$.** Empty: false. Otherwise with $b$ the **last** byte: $t = b \mathbin{\&} ($`0xff` $\oplus 128) = b \mathbin{\&} 127$; true iff $1 \leq t \leq 3$.

**`SigFlags`.** A record of four Booleans: `dersig`, `lowS`, `strictenc`, `witnessPubkeyType`.

**`checkSignatureEncoding` $f\,sig$.** If $sig$ is empty: true. Else if ($f$.dersig or $f$.lowS or $f$.strictenc) and not `isValidSignatureEncoding` $sig$: false. Else if $f$.lowS and not `isLowDERSignature` $sig$: false. Else if $f$.strictenc and not `isDefinedHashtypeSignature` $sig$: false. Else true. With all four flags false every signature passes.

**`SigVersion`.** Two constructors: `base` and `witnessV0`.

**`checkPubKeyEncoding` $f\,v\,pk$.** If $f$.strictenc and not `isCompressedOrUncompressedPubKey` $pk$: false. Else if $f$.witnessPubkeyType and $v$ = `witnessV0` and not `isCompressedPubKey` $pk$: false. Else true. With both relevant flags false, even the empty key passes.

**`checkECDSASignature` $tx\,nIn\,amount\,v\,sig\,pk\,scriptCode$.** (Note the argument order: signature, then key, then script code.) If not `pubkeyValid` $pk$: false. If $sig$ is empty: false. Otherwise let $ht$ be the last byte of $sig$, $sig'$ = $sig$ without its last byte, $hashType = ht$ (a number in $[0,255]$), and $sighash$ = `sigHashLegacy` $scriptCode\,tx\,nIn\,hashType$ if $v$ = `base`, or `sigHashWitnessV0` $scriptCode\,tx\,nIn\,hashType\,amount$ if $v$ = `witnessV0`. If $v$ = `witnessV0` and $amount < 0$: false. Else `pubkeyVerify` $pk\,sighash\,sig'$. The amount is ignored entirely in the `base` case; `pubkeyValid` is checked here and again inside `pubkeyVerify`.

**`checkSigPreTapscript` $f\,tx\,nIn\,amount\,v\,scriptCode\,sig\,pk$.** Let $sc$ = the first component of `findAndDelete` $scriptCode$ (`pushBytes` $sig$) if $v$ = `base`, or $scriptCode$ unchanged if $v$ = `witnessV0`. If `checkSignatureEncoding` $f\,sig$ is false or `checkPubKeyEncoding` $f\,v\,pk$ is false: none. Otherwise some (`checkECDSASignature` $tx\,nIn\,amount\,v\,sig\,pk\,sc$). Note that for the empty signature in `base` mode, `pushBytes` $[]$ = $[$`0x00`$]$, so every `OP_0` byte at an instruction boundary of $scriptCode$ is deleted before (the inevitably false) verification.

**Lock-time constants.** `LOCKTIME_THRESHOLD` $= 500\,000\,000$, `SEQUENCE_FINAL` $= 2^{32}-1$, `SEQUENCE_LOCKTIME_DISABLE_FLAG` $= 2^{31}$, `SEQUENCE_LOCKTIME_TYPE_FLAG` $= 2^{22}$, `SEQUENCE_LOCKTIME_MASK` $= 65535$.

**`checkLockTime` $tx\,nIn\,lockTime$** (with $lockTime$ an integer, $T$ the threshold). False unless (nLockTime $< T$ and $lockTime < T$) or (nLockTime $\geq T$ and $lockTime \geq T$). Then false if nLockTime $< lockTime$ (comparison in the integers). Then false if the sequence of input $nIn$ (or $0$ for the default input, which is therefore never "final") equals `SEQUENCE_FINAL`. Else true. A negative $lockTime$ is simply "below the threshold" and, being $\leq$ nLockTime, passes the second test.

**`checkSequence` $tx\,nIn\,sequence$.** Let $txSeq$ = the sequence of input $nIn$ (or $0$). False if $tx.\text{version} < 2$ (version is an unbounded natural number, so e.g. $2^{32}-1$ counts as $\geq 2$). False if $txSeq \mathbin{\&} 2^{31} \neq 0$. Let $mask = 2^{22} \mathbin{|} 65535$, $txMasked = txSeq \mathbin{\&} mask$, $seqMasked = (\text{toNat}\ sequence) \mathbin{\&} mask$ where a negative $sequence$ becomes $0$. False unless both masked values are $< 2^{22}$ or both are $\geq 2^{22}$. False if $txMasked < seqMasked$. Else true. The disable flag of the *argument* $sequence$ is **not** consulted (a comment defers this to the caller).

**`legacyOracle` $f\,tx\,nIn\,amount\,v\,scriptCode$.** A record whose hash fields are the serialization file's RIPEMD-160, SHA-1, SHA-256, Hash160, Hash256; whose `checkSig` is `checkSigPreTapscript` $f\,tx\,nIn\,amount\,v\,scriptCode$ awaiting the two remaining arguments (signature, key); whose `checkLockTime` is `checkLockTime` $tx\,nIn$; and whose `checkSequence` is `checkSequence` $tx\,nIn$.

**`p2pkhBytes` $h$.** $[$`0x76`, `0xa9`$]$ $\|$ `pushBytes` $h$ $\|$ $[$`0x88`, `0xac`$]$.

**`sameSkeleton` $tx\,tx'$** (a proposition). $tx'.\text{version} = tx.\text{version}$, $tx'.\text{vout} = tx.\text{vout}$, $tx'.\text{nLockTime} = tx.\text{nLockTime}$, and the lists obtained by mapping each input to the pair (prevout, nSequence) are equal — hence the input counts agree; scriptSigs and witnesses are unconstrained.

**`minimalInt` $v$** (a proposition). $v \neq []$, the first byte is $< 128$, and if $|v| > 1$ and the first byte is $0$ then the second byte is $\geq 128$. The single byte $[0]$ satisfies it; there is no upper bound on $|v|$.

**`derEncode` $r\,s\,ht$.** $[$`0x30`, $(|r|+|s|+4) \bmod 256$, `0x02`, $|r| \bmod 256]$ $\|$ $r$ $\|$ $[$`0x02`, $|s| \bmod 256]$ $\|$ $s$ $\|$ $[ht]$; total length $|r| + |s| + 7$.

**Observations the auditor may wish to weigh (descriptive only).** (i) `scalarOf` is dead code. (ii) `checkLowS` returns true on the $(0,0)$ overflow pair. (iii) The lax parser never reads the sequence-length value and ignores trailing bytes after $S$. (iv) `uint256One` read by `pubkeyVerify` is the scalar $2^{248} \bmod n$. (v) The legacy sighash strips `OP_CODESEPARATOR` from the script code; the witness-v0 sighash does not. (vi) `isCompressedOrUncompressedPubKey` rejects hybrid keys that `parsePubkey` accepts. (vii) The default input serializes to a 4-byte outpoint. (viii) `checkSequence` ignores the disable flag of its argument and maps negative arguments to $0$. (ix) `padd`'s doubling branch ignores $Q$'s ordinate. (x) `sigHashWitnessV0` uses a strict `<` for the SINGLE output index, while `sigHashLegacy` uses `≤` for its special case; the two are complementary.
