# Read-back: `Def_BitcoinHtlc.lean` (definitions, in file order)

The file introduces eight declarations in the namespace `BitcoinHtlc`: `offeredScript`, `receivedScript`, `offeredBytes`, `receivedBytes`, `CltvPasses`, a decidability instance for `CltvPasses`, `OfferedSpend` and `ReceivedSpend`. The preamble notions they depend on are rendered first, then one paragraph per definition.

**Basic notions used throughout.** A *byte* is an 8-bit word and a *byte string* (written $\mathrm{Bytes}$) is a finite list of bytes; $|b|$ denotes the length of a byte string $b$. The constant $L_{\max} = 520$ is the interpreter's maximum size of one stack element. A *flag set* $f$ consists of three Booleans $f.\mathrm{cltv}$, $f.\mathrm{csv}$, $f.\mathrm{nulldummy}$. An *oracle* $o$ is an arbitrary structure supplying eight functions with no constraints whatsoever on their behaviour: $o.\mathrm{ripemd160}, o.\mathrm{sha1}, o.\mathrm{sha256}, o.\mathrm{hash160}, o.\mathrm{hash256} : \mathrm{Bytes}\to\mathrm{Bytes}$ (so in particular $o.\mathrm{hash160}$ is *any* function from byte strings to byte strings, not necessarily RIPEMD160$\circ$SHA256, not necessarily 20-byte-valued), $o.\mathrm{checkSig} : \mathrm{Bytes}\to\mathrm{Bytes}\to \mathrm{Option}\,\mathrm{Bool}$ (first argument the signature, second the public key; the value $\mathrm{none}$ represents a script-aborting failure, $\mathrm{some}\,b$ a verdict $b$), $o.\mathrm{checkLockTime} : \mathbb{Z}\to\mathrm{Bool}$ and $o.\mathrm{checkSequence} : \mathbb{Z}\to\mathrm{Bool}$. Stacks are lists written top element first. $\mathrm{castToBool}(b)$ is: false for the empty string; for a one-byte string $[x]$, true iff $x\neq 0$ and $x \neq 0\mathrm{x}80$; for $x :: r$ with $r$ non-empty, true iff $x\neq 0$ or $\mathrm{castToBool}(r)$ (so a string of zero bytes whose last byte is $0\mathrm{x}80$ is false). $\mathrm{boolBytes}(\mathrm{true}) = [0\mathrm{x}01]$ and $\mathrm{boolBytes}(\mathrm{false}) = []$ (the empty string). The script-number encoding $\mathrm{ser}(v)$ of an integer $v$ is: $[]$ if $v = 0$; otherwise the little-endian bytes of $|v|$ with no trailing zero byte, then, if the last of those bytes has its top bit ($0\mathrm{x}80$) set, an extra byte $0\mathrm{x}80$ (for $v<0$) or $0\mathrm{x}00$ (for $v>0$) is appended, and otherwise, for $v<0$, the top bit of the last byte is set. For example $\mathrm{ser}(2) = [0\mathrm{x}02]$ and $\mathrm{ser}(32) = [0\mathrm{x}20]$. The decoding $\mathrm{num}_k(b)$ ("script number of at most $k$ bytes, non-minimal encodings allowed") is $\mathrm{none}$ if $|b| > k$, and otherwise $\mathrm{some}$ of the little-endian value of $b$ with the top bit of the last byte read as a sign (the empty string decodes to $0$).

**The number push $\mathrm{numInstr}(n)$ / $\mathrm{numBytes}(n)$.** For an integer $n$, $\mathrm{numInstr}(n)$ is the single opcode with byte value $n + 0\mathrm{x}50$ when $n = -1$ or $1 \le n \le 16$ (so $\mathrm{numInstr}(-1)$ is the opcode $0\mathrm{x}4\mathrm{f}$, $\mathrm{numInstr}(2)$ is the opcode $0\mathrm{x}52$, i.e. `OP_2`), and otherwise it is the data push of $\mathrm{ser}(n)$ (so $\mathrm{numInstr}(32)$ is the push of the one-byte string $[0\mathrm{x}20]$, and $\mathrm{numInstr}(0)$ is the push of the empty string). $\mathrm{numBytes}(n)$ is the byte-level form: the one opcode byte $n + 0\mathrm{x}50$ in the first case, and $\mathrm{pushBytes}(\mathrm{ser}(n))$ otherwise, where $\mathrm{pushBytes}(d)$ is the canonical push encoding of a byte string $d$: $[\,|d|\,] \mathbin{+\!\!+} d$ if $|d| < 0\mathrm{x}4\mathrm{c}$; $[0\mathrm{x}4\mathrm{c}, |d|] \mathbin{+\!\!+} d$ if $|d| \le 0\mathrm{xff}$; $[0\mathrm{x}4\mathrm{d}] \mathbin{+\!\!+} (\text{2 little-endian bytes of } |d|) \mathbin{+\!\!+} d$ if $|d| \le 0\mathrm{xffff}$; and $[0\mathrm{x}4\mathrm{e}] \mathbin{+\!\!+} (\text{4 little-endian bytes of } |d|) \mathbin{+\!\!+} d$ otherwise.

**The multisignature matching loop.** $\mathrm{msLoop}_o(\mathit{sigs}, \mathit{keys})$, for lists of signatures and keys (top first), is defined by recursion: it is $\mathrm{some}\,\mathrm{true}$ when $\mathit{sigs}$ is empty; $\mathrm{some}\,\mathrm{false}$ when $\mathit{sigs}$ is non-empty and $\mathit{keys}$ is empty; and for $\mathit{sigs} = s :: S$, $\mathit{keys} = k :: K$ it evaluates $o.\mathrm{checkSig}(s, k)$: if that is $\mathrm{none}$ the loop is $\mathrm{none}$; if it is $\mathrm{some}\,\mathrm{true}$ the loop is $\mathrm{some}\,\mathrm{false}$ when $|K| < |S|$ and otherwise $\mathrm{msLoop}_o(S, K)$; if it is $\mathrm{some}\,\mathrm{false}$ the loop is $\mathrm{some}\,\mathrm{false}$ when $|K| < |S| + 1$ and otherwise $\mathrm{msLoop}_o(s :: S, K)$. Unfolded on exactly two signatures and two keys, $\mathrm{msLoop}_o([s_1, s_2], [k_1, k_2])$ is: $\mathrm{none}$ if $o.\mathrm{checkSig}(s_1, k_1) = \mathrm{none}$; $\mathrm{some}\,\mathrm{false}$ if $o.\mathrm{checkSig}(s_1, k_1) = \mathrm{some}\,\mathrm{false}$ (since $1 < 2$; the second signature is then never checked); and if $o.\mathrm{checkSig}(s_1, k_1) = \mathrm{some}\,\mathrm{true}$ it is $\mathrm{none}$, $\mathrm{some}\,\mathrm{true}$ or $\mathrm{some}\,\mathrm{false}$ according as $o.\mathrm{checkSig}(s_2, k_2)$ is $\mathrm{none}$, $\mathrm{some}\,\mathrm{true}$ or $\mathrm{some}\,\mathrm{false}$.

## 5. `CltvPasses`

For a flag set $f$, an oracle $o$ and an integer $e$, $\mathrm{CltvPasses}(f, o, e)$ is the proposition
$$f.\mathrm{cltv} = \mathrm{false}\ \lor\ \bigl(0 \le e\ \land\ o.\mathrm{checkLockTime}(e) = \mathrm{true}\bigr).$$
It holds for every $e$ when the `cltv` flag is off; when the flag is on it requires $e \ge 0$ and acceptance by the oracle's (arbitrary) lock-time function. No disable bit, size bound, or relation between $e$ and $2^{32}$ or $500\,000\,000$ is part of this definition.

## 6. Decidability instance for `CltvPasses`

The file declares that, for every flag set $f$, oracle $o$ and integer $e$, the proposition $\mathrm{CltvPasses}(f, o, e)$ is decidable, by unfolding it to the disjunction/conjunction of decidable Boolean equalities and the integer comparison above. This is what allows the theorem statements to write "if $\mathrm{CltvPasses}(f, o, e)$ then … else …". It asserts nothing beyond decidability.

## 7. `OfferedSpend`

For a flag set $f$, an oracle $o$, byte strings $r, K_r, K_l, h$ and a list of byte strings $\mathit{st}$ (a stack, top first), $\mathrm{OfferedSpend}(f, o, r, K_r, K_l, h, \mathit{st})$ is the disjunction of exactly these three propositions. **(i) Revocation disjunct:** there exist byte strings $\mathit{pk}$ and $\mathit{sig}$ such that $\mathit{st} = [\mathit{pk}, \mathit{sig}]$ (a two-element stack, $\mathit{pk}$ on top), $o.\mathrm{hash160}(\mathit{pk}) = r$, and $o.\mathrm{checkSig}(\mathit{sig}, \mathit{pk}) = \mathrm{some}\,\mathrm{true}$ (the signature is checked against the stack element $\mathit{pk}$). **(ii) Preimage disjunct:** there exist byte strings $\mathit{pre}$ and $\mathit{sig}$ such that $\mathit{st} = [\mathit{pre}, \mathit{sig}]$, $o.\mathrm{hash160}(\mathit{pre}) \ne r$, $|\mathit{pre}| = 32$, $o.\mathrm{hash160}(\mathit{pre}) = h$, and $o.\mathrm{checkSig}(\mathit{sig}, K_r) = \mathrm{some}\,\mathrm{true}$. **(iii) Timeout disjunct:** there exist byte strings $x, \sigma_l, \sigma_r, d$ such that $\mathit{st} = [x, \sigma_l, \sigma_r, d]$ (a four-element stack, $x$ on top, $d$ at the bottom), $o.\mathrm{hash160}(x) \ne r$, $|x| \ne 32$, $\mathrm{msLoop}_o([\sigma_l, \sigma_r], [K_l, K_r]) = \mathrm{some}\,\mathrm{true}$ (unfolded above: both $o.\mathrm{checkSig}(\sigma_l, K_l)$ and $o.\mathrm{checkSig}(\sigma_r, K_r)$ must be $\mathrm{some}\,\mathrm{true}$), and $f.\mathrm{nulldummy} = \mathrm{true} \to d = []$ (when the `nulldummy` flag is off, $d$ may be anything). Consequently the predicate is false for every stack whose length is not $2$ or $4$, including the empty stack; disjuncts (i) and (ii) can both hold for the same two-element stack only if $o.\mathrm{hash160}$ of its top equals $r$ and differs from $r$, which is impossible, so they are mutually exclusive, while (iii) concerns four-element stacks only; no disjunct bounds the sizes of the stack elements; and $o.\mathrm{hash160}$, $o.\mathrm{checkSig}$ are the arbitrary oracle functions.

## 8. `ReceivedSpend`

For a flag set $f$, an oracle $o$, byte strings $r, K_r, K_l, h$, an integer $e$ and a stack $\mathit{st}$, $\mathrm{ReceivedSpend}(f, o, r, K_r, K_l, h, e, \mathit{st})$ is the disjunction of exactly these three propositions. **(i) Revocation disjunct:** there exist byte strings $\mathit{pk}$ and $\mathit{sig}$ such that $\mathit{st} = [\mathit{pk}, \mathit{sig}]$, $o.\mathrm{hash160}(\mathit{pk}) = r$, and $o.\mathrm{checkSig}(\mathit{sig}, \mathit{pk}) = \mathrm{some}\,\mathrm{true}$. **(ii) Success disjunct:** there exist byte strings $\mathit{pre}, \sigma_l, \sigma_r, d$ such that $\mathit{st} = [\mathit{pre}, \sigma_l, \sigma_r, d]$ ($\mathit{pre}$ on top, $d$ at the bottom), $o.\mathrm{hash160}(\mathit{pre}) \ne r$, $|\mathit{pre}| = 32$, $o.\mathrm{hash160}(\mathit{pre}) = h$, $\mathrm{msLoop}_o([\sigma_l, \sigma_r], [K_l, K_r]) = \mathrm{some}\,\mathrm{true}$, and $f.\mathrm{nulldummy} = \mathrm{true} \to d = []$. **(iii) Timeout disjunct:** there exist byte strings $x$ and $\mathit{sig}$ such that $\mathit{st} = [x, \mathit{sig}]$, $o.\mathrm{hash160}(x) \ne r$, $|x| \ne 32$, $\mathrm{CltvPasses}(f, o, e)$ holds (i.e. $f.\mathrm{cltv} = \mathrm{false}$, or $0 \le e$ and $o.\mathrm{checkLockTime}(e) = \mathrm{true}$), and $o.\mathrm{checkSig}(\mathit{sig}, K_r) = \mathrm{some}\,\mathrm{true}$. The predicate is false for every stack whose length is not $2$ or $4$ (including the empty stack); disjuncts (i) and (iii) both concern two-element stacks and are mutually exclusive via the $r$ condition on the top element; no size bound is placed on any stack element; the expiry $e$ enters only through $\mathrm{CltvPasses}$ in disjunct (iii), and only through the oracle's arbitrary $\mathrm{checkLockTime}$ function.
