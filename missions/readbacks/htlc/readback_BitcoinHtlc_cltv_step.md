# Read-back: `BitcoinHtlc.cltv_step`

**Statement.** Let $f$ be any flag set, $o$ any oracle, $s$ any interpreter state (a record of a main stack $s.\mathrm{stack}$, an alt stack, a condition stack of Booleans, and an operation count), $e$ any integer and $\mathit{rest}$ any list of byte strings, under the two hypotheses $s.\mathrm{stack} = \mathrm{ser}(e) :: \mathit{rest}$ (the top of the main stack is the script-number encoding of $e$) and $|e| < 2^{32}$ (absolute value). The theorem asserts

$$\mathrm{execOp}(f, o, \mathrm{true}, \texttt{OP\_CHECKLOCKTIMEVERIFY}, s) = \begin{cases}\mathrm{some}\,s & \text{if } \mathrm{CltvPasses}(f, o, e),\\ \mathrm{none} & \text{otherwise,}\end{cases}$$

where $\mathrm{execOp}(f, o, \mathit{fExec}, c, s)$ is the single-opcode execution function of the interpreter (the `switch` of `EvalScript`), here called with the "executing" argument $\mathit{fExec} = \mathrm{true}$ (which this opcode's branch does not consult) and the opcode byte $0\mathrm{xb}1$. Its definition at this opcode, after the earlier branches (`OP_1NEGATE`/`OP_1`…`OP_16`, `OP_NOP`) are found not to match, is: if $f.\mathrm{cltv}$ is false, the result is $\mathrm{some}\,s$ (state unchanged); otherwise, if $s.\mathrm{stack}$ is empty the result is $\mathrm{none}$; otherwise the top element $t$ is decoded as $\mathrm{num}_5(t)$, which is $\mathrm{none}$ (whence the result is $\mathrm{none}$) if $|t| > 5$ and otherwise $\mathrm{some}\,m$ with $m$ the little-endian value of $t$, the top bit of its last byte read as a sign (no minimal-encoding requirement); then the result is $\mathrm{none}$ if $m < 0$, $\mathrm{none}$ if $o.\mathrm{checkLockTime}(m) = \mathrm{false}$, and $\mathrm{some}\,s$ (the state unchanged, operand left on the stack) otherwise. The right-hand side is a case split on the decidable proposition $\mathrm{CltvPasses}(f, o, e)$ unfolded below. Note that the hypotheses do not say anything about $\mathit{rest}$, the alt stack, the condition stack or the operation count, and that the encoding $\mathrm{ser}(e)$ of an $e$ with $|e| < 2^{32}$ has at most $5$ bytes.

## Definitions unfolded

**Basic notions used throughout.** A *byte* is an 8-bit word and a *byte string* (written $\mathrm{Bytes}$) is a finite list of bytes; $|b|$ denotes the length of a byte string $b$. The constant $L_{\max} = 520$ is the interpreter's maximum size of one stack element. A *flag set* $f$ consists of three Booleans $f.\mathrm{cltv}$, $f.\mathrm{csv}$, $f.\mathrm{nulldummy}$. An *oracle* $o$ is an arbitrary structure supplying eight functions with no constraints whatsoever on their behaviour: $o.\mathrm{ripemd160}, o.\mathrm{sha1}, o.\mathrm{sha256}, o.\mathrm{hash160}, o.\mathrm{hash256} : \mathrm{Bytes}\to\mathrm{Bytes}$ (so in particular $o.\mathrm{hash160}$ is *any* function from byte strings to byte strings, not necessarily RIPEMD160$\circ$SHA256, not necessarily 20-byte-valued), $o.\mathrm{checkSig} : \mathrm{Bytes}\to\mathrm{Bytes}\to \mathrm{Option}\,\mathrm{Bool}$ (first argument the signature, second the public key; the value $\mathrm{none}$ represents a script-aborting failure, $\mathrm{some}\,b$ a verdict $b$), $o.\mathrm{checkLockTime} : \mathbb{Z}\to\mathrm{Bool}$ and $o.\mathrm{checkSequence} : \mathbb{Z}\to\mathrm{Bool}$. Stacks are lists written top element first. $\mathrm{castToBool}(b)$ is: false for the empty string; for a one-byte string $[x]$, true iff $x\neq 0$ and $x \neq 0\mathrm{x}80$; for $x :: r$ with $r$ non-empty, true iff $x\neq 0$ or $\mathrm{castToBool}(r)$ (so a string of zero bytes whose last byte is $0\mathrm{x}80$ is false). $\mathrm{boolBytes}(\mathrm{true}) = [0\mathrm{x}01]$ and $\mathrm{boolBytes}(\mathrm{false}) = []$ (the empty string). The script-number encoding $\mathrm{ser}(v)$ of an integer $v$ is: $[]$ if $v = 0$; otherwise the little-endian bytes of $|v|$ with no trailing zero byte, then, if the last of those bytes has its top bit ($0\mathrm{x}80$) set, an extra byte $0\mathrm{x}80$ (for $v<0$) or $0\mathrm{x}00$ (for $v>0$) is appended, and otherwise, for $v<0$, the top bit of the last byte is set. For example $\mathrm{ser}(2) = [0\mathrm{x}02]$ and $\mathrm{ser}(32) = [0\mathrm{x}20]$. The decoding $\mathrm{num}_k(b)$ ("script number of at most $k$ bytes, non-minimal encodings allowed") is $\mathrm{none}$ if $|b| > k$, and otherwise $\mathrm{some}$ of the little-endian value of $b$ with the top bit of the last byte read as a sign (the empty string decodes to $0$).

**The lock-time predicate.** $\mathrm{CltvPasses}(f, o, e)$, for a flag set $f$, an oracle $o$ and an integer $e$, is the proposition

$$f.\mathrm{cltv} = \mathrm{false}\ \lor\ \bigl(0 \le e\ \land\ o.\mathrm{checkLockTime}(e) = \mathrm{true}\bigr),$$

so it holds unconditionally when the `cltv` flag is off, and otherwise requires $e$ non-negative and the oracle's lock-time check to accept $e$.
