# Read-back: `BitcoinHtlc.cltv_concrete`

**Statement.** Let $f$ be any interpreter flag set, $\mathit{sf}$ any signature-layer flag set, $\mathit{tx}$ any transaction, $n$ any natural number (input index), $a$ any integer (amount), $v$ either of the two signature versions $\mathrm{base}$ or $\mathrm{witnessV0}$, $\mathit{sc}$ any byte string (script code), and $e$ any integer, under the two hypotheses $f.\mathrm{cltv} = \mathrm{true}$ and $0 \le e$. The theorem asserts

$$\mathrm{CltvPasses}\bigl(f,\ \mathcal{O}(\mathit{sf}, \mathit{tx}, n, a, v, \mathit{sc}),\ e\bigr) \iff \mathrm{CLT}(\mathit{tx}, n, e) = \mathrm{true},$$

where $\mathcal{O}(\dots)$ is the concrete "legacy oracle" built from these parameters and $\mathrm{CLT}$ is the transcribed `CheckLockTime`, both unfolded below. Since the oracle's lock-time component is by definition $\mathrm{CLT}(\mathit{tx}, n, \cdot)$, the left-hand side unfolds literally to $f.\mathrm{cltv} = \mathrm{false} \lor (0 \le e \land \mathrm{CLT}(\mathit{tx}, n, e) = \mathrm{true})$. The parameters $\mathit{sf}, a, v, \mathit{sc}$ enter only through the oracle's signature component, which the statement does not consult.

## Definitions unfolded

**Basic notions used throughout.** A *byte* is an 8-bit word and a *byte string* (written $\mathrm{Bytes}$) is a finite list of bytes; $|b|$ denotes the length of a byte string $b$. The constant $L_{\max} = 520$ is the interpreter's maximum size of one stack element. A *flag set* $f$ consists of three Booleans $f.\mathrm{cltv}$, $f.\mathrm{csv}$, $f.\mathrm{nulldummy}$. An *oracle* $o$ is an arbitrary structure supplying eight functions with no constraints whatsoever on their behaviour: $o.\mathrm{ripemd160}, o.\mathrm{sha1}, o.\mathrm{sha256}, o.\mathrm{hash160}, o.\mathrm{hash256} : \mathrm{Bytes}\to\mathrm{Bytes}$ (so in particular $o.\mathrm{hash160}$ is *any* function from byte strings to byte strings, not necessarily RIPEMD160$\circ$SHA256, not necessarily 20-byte-valued), $o.\mathrm{checkSig} : \mathrm{Bytes}\to\mathrm{Bytes}\to \mathrm{Option}\,\mathrm{Bool}$ (first argument the signature, second the public key; the value $\mathrm{none}$ represents a script-aborting failure, $\mathrm{some}\,b$ a verdict $b$), $o.\mathrm{checkLockTime} : \mathbb{Z}\to\mathrm{Bool}$ and $o.\mathrm{checkSequence} : \mathbb{Z}\to\mathrm{Bool}$. Stacks are lists written top element first. $\mathrm{castToBool}(b)$ is: false for the empty string; for a one-byte string $[x]$, true iff $x\neq 0$ and $x \neq 0\mathrm{x}80$; for $x :: r$ with $r$ non-empty, true iff $x\neq 0$ or $\mathrm{castToBool}(r)$ (so a string of zero bytes whose last byte is $0\mathrm{x}80$ is false). $\mathrm{boolBytes}(\mathrm{true}) = [0\mathrm{x}01]$ and $\mathrm{boolBytes}(\mathrm{false}) = []$ (the empty string). The script-number encoding $\mathrm{ser}(v)$ of an integer $v$ is: $[]$ if $v = 0$; otherwise the little-endian bytes of $|v|$ with no trailing zero byte, then, if the last of those bytes has its top bit ($0\mathrm{x}80$) set, an extra byte $0\mathrm{x}80$ (for $v<0$) or $0\mathrm{x}00$ (for $v>0$) is appended, and otherwise, for $v<0$, the top bit of the last byte is set. For example $\mathrm{ser}(2) = [0\mathrm{x}02]$ and $\mathrm{ser}(32) = [0\mathrm{x}20]$. The decoding $\mathrm{num}_k(b)$ ("script number of at most $k$ bytes, non-minimal encodings allowed") is $\mathrm{none}$ if $|b| > k$, and otherwise $\mathrm{some}$ of the little-endian value of $b$ with the top bit of the last byte read as a sign (the empty string decodes to $0$).

**The lock-time predicate.** $\mathrm{CltvPasses}(f, o, e)$, for a flag set $f$, an oracle $o$ and an integer $e$, is the proposition

$$f.\mathrm{cltv} = \mathrm{false}\ \lor\ \bigl(0 \le e\ \land\ o.\mathrm{checkLockTime}(e) = \mathrm{true}\bigr),$$

so it holds unconditionally when the `cltv` flag is off, and otherwise requires $e$ non-negative and the oracle's lock-time check to accept $e$.

**The concrete oracle $\mathcal{O}(\mathit{sf}, \mathit{tx}, n, a, v, \mathit{sc})$** ("legacy oracle") for signature-layer flags $\mathit{sf}$, a transaction $\mathit{tx}$, an input index $n$, an amount $a \in \mathbb{Z}$, a signature version $v \in \{\mathrm{base}, \mathrm{witnessV0}\}$ and a script-code byte string $\mathit{sc}$ is the oracle whose five hash functions are the concrete transcriptions of SHA-1, SHA-256, RIPEMD-160, $\mathrm{hash256} = \mathrm{SHA256}\circ\mathrm{SHA256}$ and $\mathrm{hash160} = \mathrm{RIPEMD160}\circ\mathrm{SHA256}$; whose $\mathrm{checkLockTime}$ is $\mathrm{CLT}(\mathit{tx}, n, \cdot)$ and $\mathrm{checkSequence}$ the analogous transcription of `CheckSequence`; and whose $\mathrm{checkSig}(\mathit{sig}, \mathit{pk})$ is the pre-tapscript check: for $v = \mathrm{witnessV0}$ the script code is used as is (for $v = \mathrm{base}$ every push of $\mathit{sig}$ is first deleted from it); it is $\mathrm{none}$ if the signature-encoding check or the public-key-encoding check under $\mathit{sf}$ fails, and otherwise $\mathrm{some}$ of the ECDSA verdict. The signature-layer flags are four Booleans $\mathrm{dersig}, \mathrm{lowS}, \mathrm{strictenc}, \mathrm{witnessPubkeyType}$; the signature-encoding check accepts an empty signature, otherwise rejects a non-strict-DER encoding when any of $\mathrm{dersig}, \mathrm{lowS}, \mathrm{strictenc}$ is set, rejects a high-S signature when $\mathrm{lowS}$ is set, and rejects an undefined hash-type byte when $\mathrm{strictenc}$ is set; the public-key-encoding check rejects a key that is neither compressed nor uncompressed when $\mathrm{strictenc}$ is set and a non-compressed key under $\mathrm{witnessV0}$ when $\mathrm{witnessPubkeyType}$ is set. The ECDSA verdict is false when the key's header byte does not announce its length ($0\mathrm{x}02/0\mathrm{x}03$ for 33 bytes, $0\mathrm{x}04/0\mathrm{x}06/0\mathrm{x}07$ for 65 bytes, anything else invalid), when the signature is empty, or when $v = \mathrm{witnessV0}$ and $a < 0$; otherwise the last byte of the signature is the hash type, the signature hash is the BIP143 digest (for $\mathrm{witnessV0}$, over $\mathit{tx}$, input $n$, the script code, the amount $a$ and the hash type) or the legacy digest (for $\mathrm{base}$), and the verdict is secp256k1 ECDSA verification of the remaining signature bytes (lax DER parsing, S normalised to the low half, the digest reduced modulo the group order) against the parsed key. $\mathrm{CLT}(\mathit{tx}, n, t)$, for $t \in \mathbb{Z}$, is: false unless either both $\mathit{tx}.\mathrm{nLockTime} < 500\,000\,000$ and $t < 500\,000\,000$, or both $\mathit{tx}.\mathrm{nLockTime} \ge 500\,000\,000$ and $t \ge 500\,000\,000$; then false if $\mathit{tx}.\mathrm{nLockTime} < t$; then false if the `nSequence` of input $n$ of $\mathit{tx}$ equals $0\mathrm{xffffffff}$, where, if $n$ is not a valid input index, a default input with `nSequence` $0$ is used; and true otherwise. When the oracle comes from a consensus flag set $F$ (Booleans $\mathrm{p2sh}, \mathrm{witness}, \mathrm{taproot}, \mathrm{dersig}, \mathrm{cltv}, \mathrm{csv}, \mathrm{nulldummy}$), the interpreter flags are $\mathrm{scriptFlagsOf}(F) = (F.\mathrm{cltv}, F.\mathrm{csv}, F.\mathrm{nulldummy})$ and the signature-layer flags are $\mathrm{sigFlagsOf}(F) = (F.\mathrm{dersig}, \mathrm{false}, \mathrm{false}, \mathrm{false})$, so under $\mathrm{sigFlagsOf}(F)$ the public-key-encoding check always passes and the signature-encoding check only rejects non-empty, non-strict-DER signatures when $F.\mathrm{dersig}$ is set.
