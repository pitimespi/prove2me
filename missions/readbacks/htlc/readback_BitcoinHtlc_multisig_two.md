# Read-back: `BitcoinHtlc.multisig_two`

**Statement.** Let $o$ be any oracle and $s_1, s_2, k_1, k_2$ any four byte strings. The theorem asserts

$$\mathrm{msLoop}_o([s_1, s_2], [k_1, k_2]) = \mathrm{some}\,\mathrm{true} \iff o.\mathrm{checkSig}(s_1, k_1) = \mathrm{some}\,\mathrm{true}\ \land\ o.\mathrm{checkSig}(s_2, k_2) = \mathrm{some}\,\mathrm{true},$$

where $\mathrm{msLoop}_o$ is the `CHECKMULTISIG` matching loop unfolded below, applied to the two-element signature list $[s_1, s_2]$ (top first) and the two-element key list $[k_1, k_2]$. Nothing is assumed about the lengths or contents of the four byte strings or about the behaviour of $o.\mathrm{checkSig}$.

---

## Definitions unfolded

**Basic notions used throughout.** A *byte* is an 8-bit word and a *byte string* (written $\mathrm{Bytes}$) is a finite list of bytes; $|b|$ denotes the length of a byte string $b$. The constant $L_{\max} = 520$ is the interpreter's maximum size of one stack element. A *flag set* $f$ consists of three Booleans $f.\mathrm{cltv}$, $f.\mathrm{csv}$, $f.\mathrm{nulldummy}$. An *oracle* $o$ is an arbitrary structure supplying eight functions with no constraints whatsoever on their behaviour: $o.\mathrm{ripemd160}, o.\mathrm{sha1}, o.\mathrm{sha256}, o.\mathrm{hash160}, o.\mathrm{hash256} : \mathrm{Bytes}\to\mathrm{Bytes}$ (so in particular $o.\mathrm{hash160}$ is *any* function from byte strings to byte strings, not necessarily RIPEMD160$\circ$SHA256, not necessarily 20-byte-valued), $o.\mathrm{checkSig} : \mathrm{Bytes}\to\mathrm{Bytes}\to \mathrm{Option}\,\mathrm{Bool}$ (first argument the signature, second the public key; the value $\mathrm{none}$ represents a script-aborting failure, $\mathrm{some}\,b$ a verdict $b$), $o.\mathrm{checkLockTime} : \mathbb{Z}\to\mathrm{Bool}$ and $o.\mathrm{checkSequence} : \mathbb{Z}\to\mathrm{Bool}$. Stacks are lists written top element first. $\mathrm{castToBool}(b)$ is: false for the empty string; for a one-byte string $[x]$, true iff $x\neq 0$ and $x \neq 0\mathrm{x}80$; for $x :: r$ with $r$ non-empty, true iff $x\neq 0$ or $\mathrm{castToBool}(r)$ (so a string of zero bytes whose last byte is $0\mathrm{x}80$ is false). $\mathrm{boolBytes}(\mathrm{true}) = [0\mathrm{x}01]$ and $\mathrm{boolBytes}(\mathrm{false}) = []$ (the empty string). The script-number encoding $\mathrm{ser}(v)$ of an integer $v$ is: $[]$ if $v = 0$; otherwise the little-endian bytes of $|v|$ with no trailing zero byte, then, if the last of those bytes has its top bit ($0\mathrm{x}80$) set, an extra byte $0\mathrm{x}80$ (for $v<0$) or $0\mathrm{x}00$ (for $v>0$) is appended, and otherwise, for $v<0$, the top bit of the last byte is set. For example $\mathrm{ser}(2) = [0\mathrm{x}02]$ and $\mathrm{ser}(32) = [0\mathrm{x}20]$. The decoding $\mathrm{num}_k(b)$ ("script number of at most $k$ bytes, non-minimal encodings allowed") is $\mathrm{none}$ if $|b| > k$, and otherwise $\mathrm{some}$ of the little-endian value of $b$ with the top bit of the last byte read as a sign (the empty string decodes to $0$).

**The multisignature matching loop.** $\mathrm{msLoop}_o(\mathit{sigs}, \mathit{keys})$, for lists of signatures and keys (top first), is defined by recursion: it is $\mathrm{some}\,\mathrm{true}$ when $\mathit{sigs}$ is empty; $\mathrm{some}\,\mathrm{false}$ when $\mathit{sigs}$ is non-empty and $\mathit{keys}$ is empty; and for $\mathit{sigs} = s :: S$, $\mathit{keys} = k :: K$ it evaluates $o.\mathrm{checkSig}(s, k)$: if that is $\mathrm{none}$ the loop is $\mathrm{none}$; if it is $\mathrm{some}\,\mathrm{true}$ the loop is $\mathrm{some}\,\mathrm{false}$ when $|K| < |S|$ and otherwise $\mathrm{msLoop}_o(S, K)$; if it is $\mathrm{some}\,\mathrm{false}$ the loop is $\mathrm{some}\,\mathrm{false}$ when $|K| < |S| + 1$ and otherwise $\mathrm{msLoop}_o(s :: S, K)$. Unfolded on exactly two signatures and two keys, $\mathrm{msLoop}_o([s_1, s_2], [k_1, k_2])$ is: $\mathrm{none}$ if $o.\mathrm{checkSig}(s_1, k_1) = \mathrm{none}$; $\mathrm{some}\,\mathrm{false}$ if $o.\mathrm{checkSig}(s_1, k_1) = \mathrm{some}\,\mathrm{false}$ (since $1 < 2$; the second signature is then never checked); and if $o.\mathrm{checkSig}(s_1, k_1) = \mathrm{some}\,\mathrm{true}$ it is $\mathrm{none}$, $\mathrm{some}\,\mathrm{true}$ or $\mathrm{some}\,\mathrm{false}$ according as $o.\mathrm{checkSig}(s_2, k_2)$ is $\mathrm{none}$, $\mathrm{some}\,\mathrm{true}$ or $\mathrm{some}\,\mathrm{false}$.
