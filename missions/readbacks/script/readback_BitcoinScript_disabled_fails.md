# Read-back: `BitcoinScript.disabled_fails`

**Binders and hypothesis.** Universally quantified: $f$, a record of three Booleans (`cltv`, `csv`, `nulldummy`), arbitrary; $o$, an oracle (eight arbitrary functions: five byte-list hash functions, a signature check returning an optional Boolean, and two integer predicates), arbitrary; $\mathit{script}$, a finite list of instructions, each either $\mathrm{push}(d)$ for a byte list $d$ or $\mathrm{op}(c)$ for a byte $c$; and $c$, a byte. Two hypotheses:

- $\mathit{hc}$: $\mathrm{isDisabled}(c) = \text{true}$, i.e. $c$ is one of the fifteen bytes $\mathtt{0x7e}$ (CAT), $\mathtt{0x7f}$ (SUBSTR), $\mathtt{0x80}$ (LEFT), $\mathtt{0x81}$ (RIGHT), $\mathtt{0x83}$ (INVERT), $\mathtt{0x84}$ (AND), $\mathtt{0x85}$ (OR), $\mathtt{0x86}$ (XOR), $\mathtt{0x8d}$ (2MUL), $\mathtt{0x8e}$ (2DIV), $\mathtt{0x95}$ (MUL), $\mathtt{0x96}$ (DIV), $\mathtt{0x97}$ (MOD), $\mathtt{0x98}$ (LSHIFT), $\mathtt{0x99}$ (RSHIFT).
- $\mathit{hmem}$: the instruction $\mathrm{op}(c)$ is a member of the list $\mathit{script}$ — it occurs at least once, at any position.

**Conclusion.** For **every** machine state $s$ (any main stack, any alt stack, any condition stack `vfExec`, any operation count `opCount`, with no constraints whatsoever):
$$\mathrm{run}(f, o, s, \mathit{script}) = \text{none}.$$
The universal quantifier over $s$ is part of the conclusion, after the hypotheses.

**Unfolding `run`.** $\mathrm{run}(f,o,s,[])$ is $\mathrm{some}(s)$ if $s.\mathrm{vfExec} = []$ and none otherwise; $\mathrm{run}(f,o,s,i :: \mathit{rest})$ applies $\mathrm{step}(f,o,s,i)$ and, if that yields $\mathrm{some}(s')$, continues as $\mathrm{run}(f,o,s',\mathit{rest})$; if the step yields none, the result is none. So the conclusion says: processing the instructions of $\mathit{script}$ in order from state $s$ ends in failure — either some instruction before the disabled one already fails, or the disabled one does.

**Unfolding `step` on the relevant instruction.** When `step` reaches $\mathrm{op}(c)$ it computes $\mathit{counted} := (\mathrm{OP\_16} < c)$, which is true for every disabled byte (all are $\ge \mathtt{0x7e} > \mathtt{0x60}$); if $201 < \mathrm{opCount} + 1$ it returns none; otherwise it increments the count and then tests $\mathrm{isDisabled}(c)$ **before** looking at whether the branch is executing — and returns none. So in the model the disabled byte fails in both executed and non-executed branches, and whether the operation-count check or the disabled check fires first does not matter for the conclusion. Every earlier instruction either succeeds (and the run proceeds toward $\mathrm{op}(c)$) or fails (none), and later instructions are irrelevant because `run` stops at the first none.

**Scope of the quantifiers.** The statement covers scripts of any length and any content around the disabled opcode: scripts that would otherwise fail for unrelated reasons, scripts consisting solely of $[\mathrm{op}(c)]$, scripts where $\mathrm{op}(c)$ appears inside an IF-branch that is not executed (vfExec containing false), scripts where $\mathrm{op}(c)$ appears after an unbalanced conditional. The initial state $s$ may already have an over-limit `opCount`, a stack exceeding $1000$ elements, or a non-empty `vfExec`; the conclusion is claimed regardless.

**What is not said.** The theorem does not say *where* or *why* the run fails — it does not say the failure happens at the disabled instruction, only that the overall result is none. It does not say anything about `evalScript` or `verifyScriptPlain` directly (though they are defined via `run`); it is stated for `run` with an arbitrary starting state rather than for `State.initial`. It does not say that scripts *without* disabled opcodes succeed, nor that the fifteen listed bytes are the *only* bytes that always cause failure (e.g. OP_RETURN, OP_VERIF-range bytes, or unknown bytes are not mentioned). It does not consider a disabled byte appearing as the data of a $\mathrm{push}$ instruction — only the instruction $\mathrm{op}(c)$ is required to be a member. It does not assert anything about the oracle or the flags; both are arbitrary and play no role in the conclusion.
