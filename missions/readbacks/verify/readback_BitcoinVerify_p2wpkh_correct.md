# Read-back: `BitcoinVerify.p2wpkh_correct`

**Binders and hypothesis.** Universally quantified: `tap`, a Taproot handler (any function from a context, a list of byte strings and a byte string to a Boolean); $c$, a verification context with fields `c.flags` (consensus flags), `c.tx` (a transaction), `c.nIn` (a natural number), `c.amount` (an integer); `sig`, `pk`, $h$, byte strings. Four hypotheses:

- `hf`: `c.flags.witness = true`;
- `hh`: $|h| = 20$;
- `hsig`: $|\mathrm{sig}| \le 520$;
- `hpk`: $|\mathrm{pk}| \le 520$.

**Conclusion.** With $\pi = \mathrm{witnessBytes}(0, h) = \mathtt{0x00}\ \mathtt{0x14}\ h$ (22 bytes) and witness stack $[\mathrm{sig}, \mathrm{pk}]$ (serialized order, `pk` last):
$$\mathrm{verifyScript}(\mathrm{tap}, c, [], \pi, [\mathrm{sig}, \mathrm{pk}]) = \mathrm{true} \iff \mathrm{castToBool}(h) = \mathrm{true} \ \wedge\ \mathrm{hash160}(\mathrm{pk}) = h \ \wedge\ \mathrm{checkSigPreTapscript}(F, c.\mathrm{tx}, c.\mathrm{nIn}, c.\mathrm{amount}, \mathrm{witnessV0}, \mathrm{p2pkhBytes}(h), \mathrm{sig}, \mathrm{pk}) = \mathrm{some}(\mathrm{true}),$$
where $F = \mathrm{sigFlagsOf}(c.\mathrm{flags}) = \langle \mathrm{dersig} = c.\mathrm{flags.dersig},\ \mathrm{false},\ \mathrm{false},\ \mathrm{false}\rangle$ and $\mathrm{p2pkhBytes}(h) = \mathtt{0x76}\ \mathtt{0xa9}\ \mathtt{0x14}\ h\ \mathtt{0x88}\ \mathtt{0xac}$.

**Unfolding the left-hand side.** The scriptSig is empty: `evalBytes c base [] []` parses to no instructions and yields the empty stack. Then $\pi$ is evaluated on it with version `base`: the byte $\mathtt{0x00}$ parses as a push of the empty string, and $\mathtt{0x14}\ h$ as a push of $h$; the resulting top-first stack is $[h, []]$. `topTrue` of it is $\mathrm{castToBool}(h)$: false when all 20 bytes are zero, or all zero except a final $\mathtt{0x80}$; so the verification is false in that case. Otherwise the native branch: `c.flags.witness` is true (`hf`); `isWitnessProgram π` is $\mathrm{some}(0, h)$ (length $22 \in [4, 42]$, first byte $0$, second byte $20 = 22 - 2$); the scriptSig is empty, so the verdict is `verifyWitnessProgram tap c [sig, pk] 0 h false` and `verifyScript` returns exactly that Boolean (no P2SH branch, no further witness check).

**Unfolding `verifyWitnessProgram` here.** Version $0$ and $|h| = 20$ (the keyhash size), so the witness must have exactly $2$ elements (it does), and the result is `executeWitnessScriptV0 c [pk, sig] (p2wpkhExec h)`: the witness is **reversed**, so `pk` is the interpreter's top and `sig` is beneath it, and `p2wpkhExec h = p2pkhBytes h`.

**Unfolding `executeWitnessScriptV0`.** No stack element may exceed 520 bytes (`hsig`, `hpk` ensure this); then `evalBytes c witnessV0 [pk, sig] (p2pkhBytes h)` runs: the 26-byte script passes the $10000$ test and parses as `OP_DUP`, `OP_HASH160`, push $h$, `OP_EQUALVERIFY`, `OP_CHECKSIG`. The interpreter (flags `scriptFlagsOf c.flags`, oracle `legacyOracle F c.tx c.nIn c.amount witnessV0 (p2pkhBytes h)`) does: `OP_DUP` → $[\mathrm{pk}, \mathrm{pk}, \mathrm{sig}]$; `OP_HASH160` → $[\mathrm{hash160}(\mathrm{pk}), \mathrm{pk}, \mathrm{sig}]$; push → $[h, \mathrm{hash160}(\mathrm{pk}), \mathrm{pk}, \mathrm{sig}]$; `OP_EQUALVERIFY` → fails unless $h = \mathrm{hash160}(\mathrm{pk})$, else $[\mathrm{pk}, \mathrm{sig}]$; `OP_CHECKSIG` pops pubkey `pk` and signature `sig` and consults the oracle, which is `checkSigPreTapscript F c.tx c.nIn c.amount witnessV0 (p2pkhBytes h) sig pk`: a result of "nothing" (an encoding check failed: `dersig` on and `sig` not valid DER, the other encoding flags being off) fails the script; `some ok` pushes $[\mathtt{0x01}]$ if `ok` else the empty string. The final stack has exactly one element and `topTrue` of it equals `ok`. Hence the left side is true iff $\mathrm{castToBool}(h)$, $\mathrm{hash160}(\mathrm{pk}) = h$, and the oracle returns `some true` — which is the right side. In `checkSigPreTapscript` with version `witnessV0`, the script code is `p2pkhBytes h` unchanged, and the ECDSA check uses the BIP143-style digest with `c.amount` and returns false when `c.amount < 0`.

**What is not said.** Nothing about any witness stack other than exactly two elements in the order `[sig, pk]`; nothing when the `witness` flag is off; nothing about $|h| \ne 20$; nothing about elements over 520 bytes; nothing about what `checkSigPreTapscript` means cryptographically — it appears unexpanded on the right; nothing about the handler `tap` or the `taproot`, `p2sh` flags, which are not consulted on this path. The theorem does not claim the key is compressed or that the signature is low-S (those flags are hard-wired off by `sigFlagsOf`).
