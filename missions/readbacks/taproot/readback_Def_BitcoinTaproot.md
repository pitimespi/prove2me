# Read-back: `Def_BitcoinTaproot.lean` (namespace `BitcoinTaproot`)

Conventions used below. A *byte* is an 8-bit value (an element of $\{0,\dots,255\}$); a *byte string* is a finite list of bytes, written with $\Vert$ for concatenation, $|s|$ for length, $s_j$ for the $j$-th byte read as a natural number (the "default" value $0$ is used wherever the file reads a position that does not exist), $s[a{:}b]$ for "drop $a$ bytes then take up to $b-a$ bytes". $\mathrm{BE}(s)$ is the big-endian natural value $\sum_j s_j\,256^{|s|-1-j}$ of a byte string of any length. $\mathrm{le32}(x)$ and $\mathrm{le64}(x)$ are the 4- and 8-byte little-endian encodings of $x \bmod 2^{32}$ and $x \bmod 2^{64}$. $\mathrm{CompactSize}(m)$ is $[m]$ if $m < 253$, $[\texttt{0xfd}] \Vert \mathrm{le16}(m)$ if $m \le \texttt{0xffff}$, $[\texttt{0xfe}] \Vert \mathrm{le32}(m)$ if $m \le \texttt{0xffffffff}$, and $[\texttt{0xff}] \Vert \mathrm{le64}(m)$ otherwise. $\mathrm{serBytes}(s) = \mathrm{CompactSize}(|s|) \Vert s$. $\mathrm{SHA256}$, $\mathrm{SHA1}$, $\mathrm{RIPEMD160}$, $\mathrm{hash160} = \mathrm{RIPEMD160}\circ\mathrm{SHA256}$ and $\mathrm{hash256} = \mathrm{SHA256}\circ\mathrm{SHA256}$ are the bundle's own implementations on byte lists. A transaction $\mathrm{tx}$ has a natural $\mathrm{version}$, a list $\mathrm{vin}$ of inputs (each: an outpoint consisting of a byte-string $\mathrm{hash}$ and a natural index $n$; a scriptSig byte string; a natural $\mathrm{nSequence}$; a witness list of byte strings), a list $\mathrm{vout}$ of outputs (each: an integer $\mathrm{nValue}$ and a byte-string $\mathrm{scriptPubKey}$), and a natural $\mathrm{nLockTime}$. $\mathrm{serOutPoint}(h, n) = h \Vert \mathrm{le32}(n)$ and $\mathrm{serTxOut}(v, s) = \mathrm{le64}(v \bmod 2^{64}) \Vert \mathrm{serBytes}(s)$ (two's complement for negative $v$). The secp256k1 constants are $p = 2^{256} - 2^{32} - 977$, the group order $n$, and the base point $G$; points are either the point at infinity ("none") or affine pairs of naturals, added with the bundle's affine formulas $\mathrm{padd}$ and multiplied by scalars with its 257-step double-and-add $\mathrm{pmul}$ (so $\mathrm{pmul}(0, P)$ is the point at infinity). "None" is the failure value of an optional result; Boolean results are $\mathrm{true}/\mathrm{false}$.

**`TAPROOT_LEAF_TAPSCRIPT`** — the natural number $\texttt{0xc0} = 192$.

**`TAPROOT_CONTROL_NODE_SIZE`** — the natural number $32$.

**`TAPROOT_CONTROL_MAX_NODE_COUNT`** — the natural number $128$.

**`ANNEX_TAG`** — the natural number $\texttt{0x50} = 80$.

**`VALIDATION_WEIGHT_OFFSET`** — the *integer* $50$.

**`VALIDATION_WEIGHT_PER_SIGOP_PASSED`** — the *integer* $50$.

**`SIGHASH_DEFAULT`** — the natural number $0$.

**`OP_CHECKSIGADD`** — the byte $\texttt{0xba} = 186$.

**`tagged`** — for a string $\mathrm{tag}$ and a byte string $m$, $\mathrm{tagged}(\mathrm{tag}, m) = \mathrm{SHA256}(\mathrm{SHA256}(T) \Vert \mathrm{SHA256}(T) \Vert m)$ where $T$ is the UTF-8 byte encoding of $\mathrm{tag}$ (the bundle's `taggedHash` applied to `ascii tag`).

**`tapleafHash`** — for a byte $v$ (the leaf version) and a byte string $\mathrm{script}$, $\mathrm{tapleafHash}(v, \mathrm{script}) = \mathrm{tagged}(\texttt{"TapLeaf"}, [v] \Vert \mathrm{CompactSize}(|\mathrm{script}|) \Vert \mathrm{script})$. No bound on $|\mathrm{script}|$ is imposed; an empty script gives $[v, \texttt{0x00}]$ as the message.

**`lexLt`** — a Boolean strict lexicographic order on byte strings, defined by recursion: $\mathrm{lexLt}([\,],[\,]) = \mathrm{false}$; $\mathrm{lexLt}([\,], b{::}bs) = \mathrm{true}$; $\mathrm{lexLt}(a{::}as, [\,]) = \mathrm{false}$; $\mathrm{lexLt}(a{::}as, b{::}bs)$ is $\mathrm{true}$ if $a < b$ (as naturals), $\mathrm{false}$ if $b < a$, and $\mathrm{lexLt}(as, bs)$ if $a = b$. Thus a proper prefix is less than its extension, and equal strings are not less.

**`tapbranchHash`** — for byte strings $a, b$: $\mathrm{tapbranchHash}(a, b) = \mathrm{tagged}(\texttt{"TapBranch"}, a \Vert b)$ if $\mathrm{lexLt}(a, b)$, and $\mathrm{tagged}(\texttt{"TapBranch"}, b \Vert a)$ otherwise (including when $a = b$, where both concatenations coincide). No length requirement on $a$ or $b$.

**`controlNodes`** — for a byte string $\mathrm{control}$, the list of its "path nodes": let $k = \lfloor (|\mathrm{control}| \dot- 33) / 32 \rfloor$, where $\dot-$ is natural-number subtraction (so $k = 0$ whenever $|\mathrm{control}| \le 33$, and also $k$ ignores any trailing fewer-than-32 bytes), and let $s$ be $\mathrm{control}$ with its first $33$ bytes dropped (all of it dropped if shorter). The result is the list of $k$ chunks $s[0{:}32],\ s[32{:}64],\ \dots,\ s[32(k-1){:}32k]$, produced by an inner recursion that, with counter $k' + 1$ and remaining string $s'$, emits "take $32$ of $s'$" and recurses on "drop $32$ of $s'$" with counter $k'$, and emits nothing at counter $0$. Because $k$ is the floor, every emitted chunk has exactly $32$ bytes.

**`taprootMerkleRoot`** — for byte strings $\mathrm{control}$ and $\mathrm{leafHash}$, the left fold of $\mathrm{tapbranchHash}$ over $\mathrm{controlNodes}(\mathrm{control})$ starting at $\mathrm{leafHash}$: $h_0 = \mathrm{leafHash}$, $h_{j+1} = \mathrm{tapbranchHash}(h_j, N_j)$ for the nodes $N_0, \dots, N_{k-1}$ in order, result $h_k$. With no nodes it is $\mathrm{leafHash}$ itself.

**`tapTweakHash`** — for byte strings $\mathrm{internal32}$ and $\mathrm{merkleRoot}$ (of any lengths), $\mathrm{tagged}(\texttt{"TapTweak"}, \mathrm{internal32} \Vert \mathrm{merkleRoot})$.

**`be32`** — for a natural $x$, the $32$-byte big-endian encoding of $x \bmod 2^{256}$ (the reverse of the $32$-byte little-endian encoding, which truncates modulo $2^{256}$).

**`xonlyTweakAddCheck`** — for a byte string $\mathrm{output32}$, a Boolean $\mathrm{parity}$, an affine point $P = (P_x, P_y)$ given as a pair of naturals (no on-curve check is made here), and a byte string $\mathrm{tweak32}$: let $t = \mathrm{BE}(\mathrm{tweak32})$; if $n \le t$ the result is $\mathrm{false}$; otherwise compute $Q = \mathrm{padd}(P, \mathrm{pmul}(t, G))$; if $Q$ is the point at infinity the result is $\mathrm{false}$; otherwise, with $Q = (q_x, q_y)$, the result is $\mathrm{true}$ iff $\mathrm{be32}(q_x) = \mathrm{output32}$ (so $\mathrm{output32}$ must have exactly $32$ bytes) and the proposition "$q_y \bmod 2 = 1$" has the same truth value as $\mathrm{parity}$. When $t = 0$, $\mathrm{pmul}(0, G)$ is the point at infinity and $Q = P$.

**`checkTapTweak`** — for byte strings $q$, $\mathrm{internal32}$, $\mathrm{merkleRoot}$ and a Boolean $\mathrm{parity}$: let $x = \mathrm{BE}(\mathrm{internal32})$ (no length check on $\mathrm{internal32}$); if $x \ge p$, or if $x^3 + 7$ is not a quadratic residue modulo $p$ (tested by $y := (x^3+7)^{(p+1)/4} \bmod p$ and $y^2 \equiv x^3 + 7$), the result is $\mathrm{false}$; otherwise let $P$ be the point with abscissa $x$ and *even* ordinate ($y$ if $y$ is even, $(p - y) \bmod p$ otherwise) and return $\mathrm{xonlyTweakAddCheck}(q, \mathrm{parity}, P, \mathrm{tapTweakHash}(\mathrm{internal32}, \mathrm{merkleRoot}))$.

**`verifyTaprootCommitment`** — for byte strings $\mathrm{control}$, $\mathrm{program}$, $\mathrm{leafHash}$: $\mathrm{checkTapTweak}(\mathrm{program},\ \mathrm{control}[1{:}33],\ \mathrm{taprootMerkleRoot}(\mathrm{control}, \mathrm{leafHash}),\ \pi)$ where $\mathrm{control}[1{:}33]$ is "drop one byte, take up to $32$" (shorter if $\mathrm{control}$ is short, empty if $|\mathrm{control}| \le 1$) and $\pi$ is the Boolean "$\mathrm{control}_0 \bmod 2 = 1$" with $\mathrm{control}_0 = 0$ when $\mathrm{control}$ is empty. No length constraint on $\mathrm{control}$ or $\mathrm{program}$ is checked in this function itself.

**`ExecData`** — a record with four fields: $\mathrm{annexPresent}$ (Boolean), $\mathrm{annexHash}$ (byte string), $\mathrm{tapleafHash}$ (byte string), $\mathrm{codeseparatorPos}$ (natural number). No invariant ties the fields together (e.g. $\mathrm{annexHash}$ may be non-empty while $\mathrm{annexPresent}$ is false).

**`sigHashSchnorr`** — a function of a transaction $\mathrm{tx}$, a list $\mathrm{spent}$ of outputs, naturals $\mathrm{inPos}$ and $\mathrm{hashType}$, a Boolean $\mathrm{tapscript}$ and an $\mathrm{ExecData}$ $e = (a, A, L, \kappa)$, returning an optional byte string. If $\neg(\mathrm{hashType} \le 3 \lor (\texttt{0x81} \le \mathrm{hashType} \le \texttt{0x83}))$, i.e. $\mathrm{hashType} \notin \{0,1,2,3,\texttt{0x81},\texttt{0x82},\texttt{0x83}\}$ (in particular $\texttt{0x80}$ is excluded), the result is none. Otherwise: $o := 1$ if $\mathrm{hashType} = 0$, else $\mathrm{hashType} \,\&\, 3$; $\iota := \mathrm{hashType} \,\&\, \texttt{0x80}$; $\mathrm{extFlag} := 1$ if $\mathrm{tapscript}$ else $0$; $\varsigma := 2\,\mathrm{extFlag} + (1 \text{ if } a \text{ else } 0)$; $I :=$ the input $\mathrm{vin}_{\mathrm{inPos}}$, or, when $\mathrm{inPos} \ge |\mathrm{vin}|$, the default input with outpoint (empty hash, index $0$), empty scriptSig, sequence $0$, empty witness. If $o = 3$: when $|\mathrm{vout}| \le \mathrm{inPos}$ the whole result is none, otherwise $\mathrm{single} := \mathrm{SHA256}(\mathrm{serTxOut}(\mathrm{vout}_{\mathrm{inPos}}))$ (the default $(-1, [\,])$ written in the code is unreachable here because of the length test); if $o \neq 3$, $\mathrm{single} := [\,]$. The result is then $\mathrm{some}$ of
$$\mathrm{tagged}\Big(\texttt{"TapSighash"},\ [\texttt{0x00},\ \mathrm{hashType} \bmod 256] \Vert \mathrm{le32}(\mathrm{version}) \Vert \mathrm{le32}(\mathrm{nLockTime}) \Vert H_{\mathrm{in}} \Vert H_{\mathrm{out}} \Vert [\varsigma] \Vert D \Vert (A \text{ if } a \text{ else } [\,]) \Vert \mathrm{single} \Vert E\Big),$$
where $H_{\mathrm{in}} = [\,]$ if $\iota = \texttt{0x80}$ and otherwise $H_{\mathrm{in}} = \mathrm{SHA256}(\Vert_{i \in \mathrm{vin}} \mathrm{serOutPoint}(i.\mathrm{prevout})) \Vert \mathrm{SHA256}(\Vert_{u \in \mathrm{spent}} \mathrm{le64}(u.\mathrm{nValue} \bmod 2^{64})) \Vert \mathrm{SHA256}(\Vert_{u \in \mathrm{spent}} \mathrm{serBytes}(u.\mathrm{scriptPubKey})) \Vert \mathrm{SHA256}(\Vert_{i \in \mathrm{vin}} \mathrm{le32}(i.\mathrm{nSequence}))$ (the $\mathrm{spent}$ list is hashed in full, whatever its length relative to $\mathrm{vin}$); $H_{\mathrm{out}} = \mathrm{SHA256}(\Vert_{u \in \mathrm{vout}} \mathrm{serTxOut}(u))$ if $o = 1$ and $[\,]$ otherwise (so for $o \in \{2, 3\}$ nothing); $D = \mathrm{serOutPoint}(I.\mathrm{prevout}) \Vert \mathrm{serTxOut}(\mathrm{spent}_{\mathrm{inPos}} \text{ or } (-1, [\,]) \text{ if } \mathrm{inPos} \ge |\mathrm{spent}|) \Vert \mathrm{le32}(I.\mathrm{nSequence})$ if $\iota = \texttt{0x80}$, and $D = \mathrm{le32}(\mathrm{inPos})$ otherwise; $E = L \Vert [\texttt{0x00}] \Vert \mathrm{le32}(\kappa)$ if $\mathrm{tapscript}$ and $[\,]$ otherwise. The default value $-1$ serializes as $\texttt{ff}^{8}$.

**`checkSchnorrSignature`** — a Boolean function of a transaction $\mathrm{tx}$, a list $\mathrm{spent}$, a natural $\mathrm{nIn}$, byte strings $\mathrm{sig}$ and $\mathrm{pubkey32}$, a Boolean $\mathrm{tapscript}$ and an $\mathrm{ExecData}$ $e$. If $|\mathrm{sig}| \neq 64$ and $|\mathrm{sig}| \neq 65$: $\mathrm{false}$. Otherwise $\mathrm{hashType} :=$ the last byte of $\mathrm{sig}$ (as a natural) if $|\mathrm{sig}| = 65$, else $0$; $\mathrm{sig}' := \mathrm{sig}$ without its last byte if $|\mathrm{sig}| = 65$, else $\mathrm{sig}$. If $|\mathrm{sig}| = 65$ and $\mathrm{hashType} = 0$: $\mathrm{false}$. Otherwise evaluate $\mathrm{sigHashSchnorr}(\mathrm{tx}, \mathrm{spent}, \mathrm{nIn}, \mathrm{hashType}, \mathrm{tapscript}, e)$: if none, $\mathrm{false}$; if $\mathrm{some}(h)$, the result is $\mathrm{schnorrVerify}(\mathrm{pubkey32}, h, \mathrm{sig}')$, the bundle's BIP340 verifier: $\mathrm{false}$ unless $|\mathrm{pubkey32}| = 32$ and $|\mathrm{sig}'| = 64$; with $r = \mathrm{BE}(\mathrm{sig}'[0{:}32])$, $s = \mathrm{BE}(\mathrm{sig}'[32{:}64])$, $\mathrm{false}$ if $p \le r$ or $n \le s$; $\mathrm{false}$ if $\mathrm{BE}(\mathrm{pubkey32})$ does not lift (as in `checkTapTweak`) to a point $P$ with even ordinate; else with $c = \mathrm{BE}(\mathrm{tagged}(\texttt{"BIP0340/challenge"}, \mathrm{sig}'[0{:}32] \Vert \mathrm{pubkey32} \Vert h)) \bmod n$ and $R = \mathrm{padd}(\mathrm{pmul}(s, G), \mathrm{pmul}((n - c) \bmod n, P))$, $\mathrm{false}$ if $R$ is the point at infinity, else $\mathrm{true}$ iff $R_y$ is even and $R_x = r$. This function itself imposes no length condition on $\mathrm{pubkey32}$.

**`isOpSuccess`** — for a natural $c$, the Boolean "$c = 80$ or $c = 98$ or $126 \le c \le 129$ or $131 \le c \le 134$ or $137 \le c \le 138$ or $141 \le c \le 142$ or $149 \le c \le 153$ or $187 \le c \le 254$".

**`opSuccessScan`** — a function of a fuel $f \in \mathbb{N}$ and a byte string $s$ returning an optional Boolean, by recursion: if $s = [\,]$, $\mathrm{some}(\mathrm{false})$ (whatever $f$); else if $f = 0$, none; else read one instruction from $s$ with the bundle's `getOp` (first byte $o$: if $o \le \texttt{0x4e}$ it is a push — of $o$ bytes when $o < \texttt{0x4c}$, or of a length given by the next 1, 2 or 4 little-endian bytes for $o = \texttt{0x4c}, \texttt{0x4d}, \texttt{0x4e}$ — and the read fails if the length bytes or the data are missing; if $o > \texttt{0x4e}$ it is the opcode $o$ with no data); if the read fails, none; if it is a push, recurse on the remainder with fuel $f - 1$; if it is an opcode $c$ with $\mathrm{isOpSuccess}(c)$, $\mathrm{some}(\mathrm{true})$; otherwise recurse on the remainder with fuel $f - 1$.

**`TapCtx`** — a record with fields $\mathrm{flags}$ (the Script-layer flag record: Booleans $\mathrm{cltv}$, $\mathrm{csv}$, $\mathrm{nulldummy}$), $\mathrm{tx}$ (a transaction), $\mathrm{spent}$ (a list of outputs), $\mathrm{nIn}$ (a natural).

**`tapOracle`** — for a $\mathrm{TapCtx}$ $c$, the Script-layer oracle record whose hash fields are the bundle's $\mathrm{RIPEMD160}$, $\mathrm{SHA1}$, $\mathrm{SHA256}$, $\mathrm{hash160}$, $\mathrm{hash256}$; whose $\mathrm{checkSig}$ field is the constant function returning none for every (signature, key) pair (a script failure if ever consulted); whose $\mathrm{checkLockTime}$ is the bundle's `checkLockTime` for $c.\mathrm{tx}$, $c.\mathrm{nIn}$ (an integer lock time $\lambda$ is accepted iff $\lambda$ and $\mathrm{tx}.\mathrm{nLockTime}$ are on the same side of $500{,}000{,}000$, $\lambda \le \mathrm{tx}.\mathrm{nLockTime}$, and the sequence of input $\mathrm{nIn}$ — default input if out of range — is not $\texttt{0xffffffff}$); and whose $\mathrm{checkSequence}$ is the bundle's `checkSequence` for $c.\mathrm{tx}$, $c.\mathrm{nIn}$ (rejects if $\mathrm{tx}.\mathrm{version} < 2$ or the input's sequence has bit $31$ set; otherwise compares the masked (bits $0$–$15$ and $22$) values, requiring same type flag and $\mathrm{seq}_{\text{masked}} \le \mathrm{txseq}_{\text{masked}}$, where the script operand is converted to a natural by truncating negatives to $0$).

**`TapState`** — a record with fields $\mathrm{st}$ (the Script-layer interpreter state: main $\mathrm{stack}$, $\mathrm{altstack}$, condition stack $\mathrm{vfExec}$ — all lists with the top first — and a natural $\mathrm{opCount}$), $\mathrm{weightLeft}$ (an integer), $\mathrm{codeseparatorPos}$ (a natural) and $\mathrm{opcodePos}$ (a natural).

**`evalChecksigTapscript`** — for a $\mathrm{TapCtx}$ $c$, an $\mathrm{ExecData}$ $e$, byte strings $\mathrm{sig}$ and $\mathrm{pubkey}$, and an integer $w$, an optional pair (Boolean, integer): $\mathrm{success} := (\mathrm{sig} \neq [\,])$; $w' := w - 50$ if $\mathrm{success}$ else $w$ (integer arithmetic, may be negative); if $\mathrm{success}$ and $w' < 0$: none; else if $|\mathrm{pubkey}| = 0$: none; else if $|\mathrm{pubkey}| = 32$: none if $\mathrm{success}$ and $\mathrm{checkSchnorrSignature}(c.\mathrm{tx}, c.\mathrm{spent}, c.\mathrm{nIn}, \mathrm{sig}, \mathrm{pubkey}, \mathrm{true}, e)$ is $\mathrm{false}$, otherwise $\mathrm{some}(\mathrm{success}, w')$; else (any other non-zero key length) $\mathrm{some}(\mathrm{success}, w')$ with no verification. With an empty signature, no verification is performed for any key length, and the weight is unchanged.

**`tapExecOp`** — for a $\mathrm{TapCtx}$ $c$, an $\mathrm{ExecData}$ $e$, a Boolean $\mathrm{fExec}$, an opcode byte $\mathrm{op}$ and a $\mathrm{TapState}$ $\mathrm{ts}$ with state $s = \mathrm{ts}.\mathrm{st}$, an optional $\mathrm{TapState}$; let $e'$ be $e$ with $\mathrm{codeseparatorPos} := \mathrm{ts}.\mathrm{codeseparatorPos}$. Cases in order. (1) $\mathrm{op} \in \{\texttt{0x63}, \texttt{0x64}\}$ (`OP_IF`, `OP_NOTIF`): if $\mathrm{fExec}$, then none if the main stack is empty, none if its top $t$ has $|t| > 1$ or ($|t| = 1$ and $t_0 \neq 1$), and otherwise the legacy `execOp` result (pop $t$, push "$t$ is true" — any non-zero byte except a lone final $\texttt{0x80}$ — negated for `OP_NOTIF`, onto $\mathrm{vfExec}$) placed into $\mathrm{ts}$; if not $\mathrm{fExec}$, the legacy result (push $\mathrm{false}$ onto $\mathrm{vfExec}$) placed into $\mathrm{ts}$. (2) $\mathrm{op} \in \{\texttt{0xac}, \texttt{0xad}\}$ (`OP_CHECKSIG`, `OP_CHECKSIGVERIFY`), regardless of $\mathrm{fExec}$: none unless the stack is $\mathrm{pubkey} :: \mathrm{sig} :: \mathrm{rest}$; then $\mathrm{evalChecksigTapscript}(c, e', \mathrm{sig}, \mathrm{pubkey}, \mathrm{ts}.\mathrm{weightLeft})$: none gives none; $\mathrm{some}(\mathrm{success}, w')$ gives, for `OP_CHECKSIGVERIFY`, $\mathrm{ts}$ with stack $\mathrm{rest}$ and weight $w'$ if $\mathrm{success}$, else none; for `OP_CHECKSIG`, $\mathrm{ts}$ with stack $\mathrm{boolBytes}(\mathrm{success}) :: \mathrm{rest}$ ($[1]$ or $[\,]$) and weight $w'$. (3) $\mathrm{op} = \texttt{0xba}$ (`OP_CHECKSIGADD`), regardless of $\mathrm{fExec}$: none unless the stack is $\mathrm{pubkey} :: \mathrm{numv} :: \mathrm{sig} :: \mathrm{rest}$; none if $|\mathrm{numv}| > 4$; otherwise $\mathrm{num}$ is the script-number value of $\mathrm{numv}$ (little-endian magnitude with sign bit in the last byte, no minimality requirement, empty is $0$); then $\mathrm{evalChecksigTapscript}(c, e', \mathrm{sig}, \mathrm{pubkey}, \mathrm{ts}.\mathrm{weightLeft})$: none gives none, else $\mathrm{ts}$ with stack $\mathrm{serialize}(\mathrm{num} + [\mathrm{success}]) :: \mathrm{rest}$ (minimal script-number encoding) and weight $w'$. (4) $\mathrm{op} \in \{\texttt{0xae}, \texttt{0xaf}\}$ (`OP_CHECKMULTISIG(VERIFY)`): none, regardless of everything else. (5) $\mathrm{op} = \texttt{0xab}$ (`OP_CODESEPARATOR`), regardless of $\mathrm{fExec}$: $\mathrm{ts}$ with $\mathrm{codeseparatorPos} := \mathrm{ts}.\mathrm{opcodePos}$ and nothing else changed. (6) Any other byte: the legacy `execOp` with flags $c.\mathrm{flags}$, oracle $\mathrm{tapOracle}(c)$, $\mathrm{fExec}$, $\mathrm{op}$ and $s$, placed into $\mathrm{ts}$ (none when it fails; it fails for unknown opcodes, `OP_RETURN`, `OP_VERIF`/`OP_VERNOTIF`, etc., and treats $\texttt{0x4f}$–$\texttt{0x60}$ as number pushes). Only $\mathrm{st}$ is touched in case (6); $\mathrm{weightLeft}$, $\mathrm{codeseparatorPos}$, $\mathrm{opcodePos}$ are preserved there.

**`tapStep`** — for $c$, $e$, a $\mathrm{TapState}$ $\mathrm{ts}$ and one parsed instruction, an optional $\mathrm{TapState}$. For a push of data $d$: none if $|d| > 520$; otherwise $s' := s$ with $d$ pushed on the main stack if all entries of $\mathrm{vfExec}$ are $\mathrm{true}$ (vacuously so when empty), else $s' := s$; none if $|s'.\mathrm{stack}| + |s'.\mathrm{altstack}| > 1000$; else $\mathrm{ts}$ with $\mathrm{st} := s'$ and $\mathrm{opcodePos}$ incremented by $1$. For an opcode byte $\mathrm{op}$: $\mathrm{fExec} :=$ all entries of $\mathrm{vfExec}$ are $\mathrm{true}$; none if $\mathrm{op}$ is one of the fifteen disabled opcodes ($\texttt{0x7e}$–$\texttt{0x81}$, $\texttt{0x83}$–$\texttt{0x86}$, $\texttt{0x8d}$, $\texttt{0x8e}$, $\texttt{0x95}$–$\texttt{0x99}$); otherwise $r := \mathrm{tapExecOp}(c, e, \mathrm{fExec}, \mathrm{op}, \mathrm{ts})$ if $\mathrm{fExec}$ or $\texttt{0x63} \le \mathrm{op} \le \texttt{0x68}$ (this range includes $\texttt{0x65}$, $\texttt{0x66}$), and $r := \mathrm{some}(\mathrm{ts})$ otherwise; if $r$ is none, none; else, for $r = \mathrm{some}(\mathrm{ts}')$, none if $|\mathrm{ts}'.\mathrm{st}.\mathrm{stack}| + |\mathrm{ts}'.\mathrm{st}.\mathrm{altstack}| > 1000$, else $\mathrm{ts}'$ with $\mathrm{opcodePos}$ incremented by $1$. No operation count is kept.

**`tapRun`** — for $c$, $e$, a $\mathrm{TapState}$ and a parsed script (list of instructions), an optional $\mathrm{TapState}$: on the empty script, $\mathrm{some}(\mathrm{ts})$ if $\mathrm{ts}.\mathrm{st}.\mathrm{vfExec}$ is empty and none otherwise; on $i :: \mathrm{rest}$, apply $\mathrm{tapStep}$ to $i$, propagate none, and continue on $\mathrm{rest}$ from the new state.

**`executeTapscript`** — a Boolean function of a $\mathrm{TapCtx}$ $c$, an $\mathrm{ExecData}$ $e$, a list $\mathrm{stack}$ of byte strings (top first), a byte string $\mathrm{script}$ and an integer $\mathrm{weight}$. Evaluate $\mathrm{opSuccessScan}(|\mathrm{script}|, \mathrm{script})$: none gives $\mathrm{false}$; $\mathrm{some}(\mathrm{true})$ gives $\mathrm{true}$ at once (no further checks of any kind); $\mathrm{some}(\mathrm{false})$ continues: $\mathrm{false}$ if $|\mathrm{stack}| > 1000$; $\mathrm{false}$ if some element of $\mathrm{stack}$ is longer than $520$ bytes; $\mathrm{false}$ if the bundle's `parseScript` of $\mathrm{script}$ fails (it cannot, given the scan returned $\mathrm{some}(\mathrm{false})$, but the branch is present); otherwise run $\mathrm{tapRun}$ from the initial $\mathrm{TapState}$ (main stack $\mathrm{stack}$, empty alt stack, empty condition stack, op count $0$, $\mathrm{weightLeft} = \mathrm{weight}$, $\mathrm{codeseparatorPos} = \texttt{0xFFFFFFFF}$, $\mathrm{opcodePos} = 0$) over the parsed script: none gives $\mathrm{false}$; otherwise the result is "the final main stack has exactly one element, and that element is true" (non-empty with some non-zero byte, not a negative zero). No maximum script size is checked here.

**`witnessSerializedSize`** — for a list $W$ of byte strings, the natural number $|\mathrm{CompactSize}(|W|) \Vert \Vert_{w \in W} \mathrm{serBytes}(w)|$, i.e. the length of the CompactSize count followed by each element with its own CompactSize length prefix.

**`hasAnnex`** — for a list $W$ of byte strings, the Boolean "$|W| \ge 2$, and the last element of $W$ is of the form $b :: \_$ (non-empty) with $b = \texttt{0x50}$ as a natural". An empty last element, or a list of fewer than two elements, gives $\mathrm{false}$.

**`taprootHandler`** — for a list $\mathrm{spent}$ of outputs, the function (of type `BitcoinVerify.TaprootHandler`) taking a verification context $c$ (fields: consensus flags $\mathrm{p2sh}, \mathrm{witness}, \mathrm{taproot}, \mathrm{dersig}, \mathrm{cltv}, \mathrm{csv}, \mathrm{nulldummy}$; a transaction $\mathrm{tx}$; a natural $\mathrm{nIn}$; an integer $\mathrm{amount}$), a witness list $W$ (last element on top) and a byte string $\mathrm{program}$, and returning a Boolean. If $W = [\,]$: $\mathrm{false}$. Otherwise: $\mathrm{tc} := (\,(c.\mathrm{flags}.\mathrm{cltv}, c.\mathrm{flags}.\mathrm{csv}, c.\mathrm{flags}.\mathrm{nulldummy}),\ c.\mathrm{tx},\ \mathrm{spent},\ c.\mathrm{nIn}\,)$; if $\mathrm{hasAnnex}(W)$, the annex is the last element of $W$ and $\mathrm{stack} := W$ without its last element, otherwise there is no annex and $\mathrm{stack} := W$; $e_0 := (\text{annex present},\ \mathrm{SHA256}(\mathrm{serBytes}(\mathrm{annex})) \text{ if present else } [\,],\ [\,],\ \texttt{0xFFFFFFFF})$. If $|\mathrm{stack}| = 1$ (key path): the result is $\mathrm{checkSchnorrSignature}(c.\mathrm{tx}, \mathrm{spent}, c.\mathrm{nIn}, \mathrm{stack}_0, \mathrm{program}, \mathrm{false}, e_0)$, where $\mathrm{stack}_0$ is the unique element. Otherwise (script path): $\mathrm{false}$ if $\mathrm{stack}$ is empty (unreachable given $W \neq [\,]$, since an annex is only removed when $|W| \ge 2$); $\mathrm{control} :=$ the last element, removed; $\mathrm{false}$ if nothing remains (likewise unreachable, as $|\mathrm{stack}| \ge 2$ here); $\mathrm{script} :=$ the new last element, removed; $\mathrm{false}$ if $|\mathrm{control}| < 33$ or $|\mathrm{control}| > 4129$ or $(|\mathrm{control}| - 33) \bmod 32 \neq 0$; $v := \mathrm{control}_0 \,\&\, \texttt{0xfe}$; $\ell := \mathrm{tapleafHash}(\langle v \rangle_8, \mathrm{script})$; $\mathrm{false}$ if $\mathrm{verifyTaprootCommitment}(\mathrm{control}, \mathrm{program}, \ell)$ is $\mathrm{false}$; if $v = \texttt{0xc0}$, the result is $\mathrm{executeTapscript}(\mathrm{tc},\ e_0 \text{ with } \mathrm{tapleafHash} := \ell,\ \mathrm{reverse}(\mathrm{stack}),\ \mathrm{script},\ \mathrm{witnessSerializedSize}(W) + 50)$ (the size is that of the *whole* original witness $W$, annex included, coerced to an integer); if $v \neq \texttt{0xc0}$, the result is $\mathrm{true}$. The fields $c.\mathrm{flags}.\mathrm{taproot}$, $c.\mathrm{flags}.\mathrm{witness}$, $c.\mathrm{flags}.\mathrm{p2sh}$, $c.\mathrm{flags}.\mathrm{dersig}$ and $c.\mathrm{amount}$ are not consulted; the length of $\mathrm{program}$ is not checked here (a non-32-byte program can only fail inside the tweak check or the signature check).

**`verifyScriptFull`** — for a list $\mathrm{spent}$, a context $c$, byte strings $\mathrm{scriptSig}$, $\mathrm{scriptPubKey}$ and a witness list $W$: the Boolean `BitcoinVerify.verifyScript` with the Taproot handler $\mathrm{taprootHandler}(\mathrm{spent})$ plugged in. Unfolded from the imported file, that is: evaluate $\mathrm{scriptSig}$ with the legacy interpreter from an empty stack (failing — $\mathrm{false}$ — if longer than $10{,}000$ bytes, unparsable, or if execution fails), then $\mathrm{scriptPubKey}$ from the resulting stack; $\mathrm{false}$ if the resulting top is not true; if $c.\mathrm{flags}.\mathrm{witness}$ and $\mathrm{scriptPubKey}$ is a witness program (length $4$–$42$, first byte $0$ or $\texttt{0x51}$–$\texttt{0x60}$, second byte equal to length $-2$), then $\mathrm{false}$ if $\mathrm{scriptSig} \neq [\,]$, else the verdict of the witness-program verifier — which for version $1$, a $32$-byte program and not-P2SH returns $\mathrm{true}$ if $c.\mathrm{flags}.\mathrm{taproot}$ is off and otherwise $\mathrm{taprootHandler}(\mathrm{spent})(c, W, \mathrm{program})$, and otherwise handles version $0$ (P2WSH/P2WPKH) or returns $\mathrm{true}$ for other versions; otherwise, if $c.\mathrm{flags}.\mathrm{p2sh}$ and $\mathrm{scriptPubKey}$ is `OP_HASH160 <20 bytes> OP_EQUAL`, the P2SH path (push-only scriptSig, redeem script evaluation, nested witness program with the same version dispatch and $\mathrm{isP2sh} = \mathrm{true}$, in which case version $1$ is *not* routed to the Taproot handler but accepted as $\mathrm{true}$, and a non-empty witness without a witness program is $\mathrm{false}$); otherwise $\mathrm{false}$ if $c.\mathrm{flags}.\mathrm{witness}$ and $W \neq [\,]$, else $\mathrm{true}$.

**`p2trBytes`** — for a byte string $q$, the byte string $[\texttt{0x51}] \Vert \mathrm{push}(q)$, where $\mathrm{push}(q)$ is the bundle's canonical push encoding of $q$ (`witnessBytes 1 q`); for a $32$-byte $q$ this is $[\texttt{0x51}, \texttt{0x20}] \Vert q$. No length constraint on $q$ is imposed.
