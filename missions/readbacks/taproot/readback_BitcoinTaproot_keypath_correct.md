# Read-back: `BitcoinTaproot.keypath_correct`

**Binders.** $\mathrm{spent}$ : a list of transaction outputs (integer value, byte-string script); $c$ : a verification context `BitcoinVerify.Ctx` (fields $\mathrm{flags}$ — Booleans `p2sh`, `witness`, `taproot`, `dersig`, `cltv`, `csv`, `nulldummy` —, $\mathrm{tx}$ a transaction with natural $\mathrm{version}$, inputs $\mathrm{vin}$, outputs $\mathrm{vout}$, natural $\mathrm{nLockTime}$, $\mathrm{nIn} \in \mathbb{N}$, $\mathrm{amount} \in \mathbb{Z}$); $\mathrm{sig}, q$ : byte strings.

**Hypotheses.** None.

**Conclusion (an equivalence).**

$$\mathrm{taprootHandler}(\mathrm{spent})(c, [\mathrm{sig}], q) = \mathrm{true}$$

if and only if there exist a byte string $\mathrm{body}$, a natural $\mathrm{ht}$ and a byte string $h$ with

1. $|\mathrm{body}| = 64$;
2. either ($\mathrm{sig} = \mathrm{body}$ and $\mathrm{ht} = 0$) or (there is an 8-bit value $b$ with $\mathrm{sig} = \mathrm{body} \Vert [b]$, $b = \mathrm{ht}$ as naturals, and $\mathrm{ht} \neq 0$);
3. $\mathrm{sigHashSchnorr}\big(c.\mathrm{tx}, \mathrm{spent}, c.\mathrm{nIn}, \mathrm{ht}, \mathrm{false}, (\mathrm{false}, [\,], [\,], \texttt{0xFFFFFFFF})\big) = \mathrm{some}(h)$, the last argument being the `ExecData` with no annex, empty annex hash, empty tapleaf hash and code-separator position $2^{32}-1$;
4. $\mathrm{schnorrVerify}(q, h, \mathrm{body}) = \mathrm{true}$.

**The left side, unfolded.** $\mathrm{taprootHandler}(\mathrm{spent})(c, W, q)$ returns $\mathrm{false}$ for empty $W$; otherwise computes $\mathrm{hasAnnex}(W)$ ("$|W| \ge 2$ and the last element is non-empty and starts with $\texttt{0x50}$"), strips the annex if present, builds $e_0$ = (annex present, SHA-256 of the CompactSize-prefixed annex or $[\,]$, $[\,]$, $\texttt{0xFFFFFFFF}$), and if the remaining stack has exactly one element $x$ returns $\mathrm{checkSchnorrSignature}(c.\mathrm{tx}, \mathrm{spent}, c.\mathrm{nIn}, x, q, \mathrm{false}, e_0)$; otherwise it takes the script path. For $W = [\mathrm{sig}]$ there is no annex ($|W| = 1$), the stack is $[\mathrm{sig}]$, $e_0 = (\mathrm{false}, [\,], [\,], \texttt{0xFFFFFFFF})$, and the left side equals $\mathrm{checkSchnorrSignature}(c.\mathrm{tx}, \mathrm{spent}, c.\mathrm{nIn}, \mathrm{sig}, q, \mathrm{false}, e_0) = \mathrm{true}$. The flag $c.\mathrm{flags}.\mathrm{taproot}$ and $c.\mathrm{amount}$ play no role.

**The signature check, unfolded.** $\mathrm{checkSchnorrSignature}(\mathrm{tx}, S, i, \mathrm{sig}, \mathrm{pk}, \tau, e)$ (with $S$ the spent-output list, $i$ the input index, $\tau$ the tapscript flag, $e$ the `ExecData`) is the Boolean computed as follows: if $|\mathrm{sig}| \neq 64$ and $|\mathrm{sig}| \neq 65$, $\mathrm{false}$; otherwise let $t := $ the last byte of $\mathrm{sig}$ as a natural if $|\mathrm{sig}| = 65$, else $t := 0$, and $\mathrm{sig}' := \mathrm{sig}$ without its last byte if $|\mathrm{sig}| = 65$, else $\mathrm{sig}$; if $|\mathrm{sig}| = 65$ and $t = 0$, $\mathrm{false}$; otherwise compute $\mathrm{sigHashSchnorr}(\mathrm{tx}, S, i, t, \tau, e)$ — if that is $\mathrm{none}$, $\mathrm{false}$; if it is $\mathrm{some}(h)$, the result is $\mathrm{schnorrVerify}(\mathrm{pk}, h, \mathrm{sig}')$.

$\mathrm{schnorrVerify}(\mathrm{pk}, m, \sigma)$ is: $\mathrm{false}$ if $|\mathrm{pk}| \neq 32$ or $|\sigma| \neq 64$; let $r := \mathrm{BE}(\sigma[0{:}32])$ and $s := \mathrm{BE}(\sigma[32{:}64])$ (big-endian values); $\mathrm{false}$ if $p \le r$ or $n \le s$ ($p = 2^{256} - 2^{32} - 977$ the field prime, $n$ the secp256k1 group order); let $P := \mathrm{liftX}(\mathrm{BE}(\mathrm{pk}))$, which is $\mathrm{none}$ if $\mathrm{BE}(\mathrm{pk}) \ge p$, and otherwise, with $x := \mathrm{BE}(\mathrm{pk})$ and $y := (x^3 + 7)^{(p+1)/4} \bmod p$, is the point $(x, y)$ if $y$ is even, or $(x, p - y)$ if $y$ is odd, provided $y^2 \equiv x^3 + 7 \pmod p$, and $\mathrm{none}$ otherwise; $\mathrm{false}$ if $P$ is $\mathrm{none}$; let $c := \mathrm{BE}\big(\mathrm{tagged}(\texttt{"BIP0340/challenge"}, \sigma[0{:}32] \,\Vert\, \mathrm{pk} \,\Vert\, m)\big) \bmod n$; let $R := s\cdot G + ((n - c) \bmod n)\cdot P$ computed with the bundle's affine addition/doubling formulas (with the point at infinity as $\mathrm{none}$) and a 257-step double-and-add; $\mathrm{false}$ if $R$ is $\mathrm{none}$; otherwise $\mathrm{true}$ iff $y_R$ is even and $x_R = r$.

$\mathrm{sigHashSchnorr}(\mathrm{tx}, S, i, t, \tau, e)$, with $e = (a, A, L, \kappa)$ (annex present, annex hash, tapleaf hash, code-separator position), is: $\mathrm{none}$ unless $t \in \{0,1,2,3,\texttt{0x81},\texttt{0x82},\texttt{0x83}\}$; let $o := 1$ if $t = 0$ else $t \,\&\, 3$; $\iota := t \,\&\, \texttt{0x80}$; $\varsigma := 2\,[\tau] + [a]$ (so $0$, $1$, $2$ or $3$); $I :=$ the $i$-th input of $\mathrm{tx}$, or, if $i \ge |\mathrm{vin}|$, the default input (prevout with *empty* hash and index $0$, empty scriptSig, sequence $0$, empty witness); if $o = 3$ then $\mathrm{single} :=$ $\mathrm{none}$ when $|\mathrm{vout}| \le i$ and otherwise $\mathrm{SHA256}(\mathrm{serTxOut}(\mathrm{vout}_i))$, else $\mathrm{single} := [\,]$; if $\mathrm{single}$ is $\mathrm{none}$ the result is $\mathrm{none}$; otherwise the result is $\mathrm{some}$ of
$$\mathrm{tagged}\Big(\texttt{"TapSighash"},\ [\texttt{0x00}, t \bmod 256] \,\Vert\, \mathrm{le32}(\mathrm{version}) \,\Vert\, \mathrm{le32}(\mathrm{nLockTime}) \,\Vert\, H_{\mathrm{in}} \,\Vert\, H_{\mathrm{out}} \,\Vert\, [\varsigma] \,\Vert\, D \,\Vert\, (A \text{ if } a \text{ else } [\,]) \,\Vert\, \mathrm{single} \,\Vert\, (L \Vert [\texttt{0x00}] \Vert \mathrm{le32}(\kappa) \text{ if } \tau \text{ else } [\,])\Big)$$
where $H_{\mathrm{in}}$ is empty if $\iota = \texttt{0x80}$ and otherwise is the concatenation of four SHA-256 digests: of all inputs' serialized outpoints (hash $\Vert$ le32 index), of all elements of $S$'s values as 8-byte little-endian two's complement, of all elements of $S$'s scriptPubKeys each prefixed by its CompactSize length, and of all inputs' le32 sequences; $H_{\mathrm{out}}$ is the SHA-256 of all outputs serialized (le64 two's-complement value $\Vert$ CompactSize-prefixed script) if $o = 1$, and empty otherwise; $D$ is $\mathrm{serOutPoint}(I.\mathrm{prevout}) \,\Vert\, \mathrm{serTxOut}(S_i \text{ or the default output } (-1, [\,]) \text{ if } i \ge |S|) \,\Vert\, \mathrm{le32}(I.\mathrm{nSequence})$ if $\iota = \texttt{0x80}$, and $\mathrm{le32}(i)$ otherwise. $\mathrm{tagged}(T, m) = \mathrm{SHA256}(\mathrm{SHA256}(T)\Vert\mathrm{SHA256}(T)\Vert m)$ with $T$ the UTF-8 bytes of the tag; $\mathrm{le32}(x)$ is the 4-byte little-endian encoding of $x \bmod 2^{32}$; CompactSize is 1 byte below $253$, else $\texttt{0xfd}$ + 2 bytes up to $\texttt{0xffff}$, else $\texttt{0xfe}$ + 4 bytes up to $\texttt{0xffffffff}$, else $\texttt{0xff}$ + 8 bytes. In this instance $\tau = \mathrm{false}$ and $a = \mathrm{false}$, so $\varsigma = 0$, no annex hash and no tapscript extension appear in the message, and $t = \mathrm{ht}$ must lie in $\{0,1,2,3,\texttt{0x81},\texttt{0x82},\texttt{0x83}\}$ for clause 3 to hold; with $\mathrm{ht} \in \{3, \texttt{0x83}\}$ it additionally requires $c.\mathrm{nIn} < |\mathrm{vout}|$.
