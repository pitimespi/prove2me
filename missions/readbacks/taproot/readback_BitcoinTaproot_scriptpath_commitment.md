# Read-back: `BitcoinTaproot.scriptpath_commitment`

**Binders.** $\mathrm{spent}$ : a list of transaction outputs; $c$ : a verification context `BitcoinVerify.Ctx` (fields $\mathrm{flags}$ — Booleans `p2sh`, `witness`, `taproot`, `dersig`, `cltv`, `csv`, `nulldummy` —, $\mathrm{tx}$, $\mathrm{nIn} \in \mathbb{N}$, $\mathrm{amount} \in \mathbb{Z}$); $\mathrm{stack}$ : a list of byte strings; $\mathrm{script}, \mathrm{control}, q$ : byte strings.

Throughout, $W := \mathrm{stack} \,\Vert\, [\mathrm{script}, \mathrm{control}]$ denotes the witness list consisting of the elements of $\mathrm{stack}$ followed by $\mathrm{script}$ and then $\mathrm{control}$ (so $|W| \ge 2$ and $\mathrm{control}$ is last).

**Hypotheses.**
1. $\mathrm{hasAnnex}(W) = \mathrm{false}$. Unfolded: $\mathrm{hasAnnex}(W)$ is "$|W| \ge 2$ and the last element of $W$ is non-empty with first byte equal to $\texttt{0x50}$"; since $|W| \ge 2$ holds, the hypothesis says exactly that $\mathrm{control}$ is empty or its first byte is not $\texttt{0x50}$.
2. $\mathrm{taprootHandler}(\mathrm{spent})(c, W, q) = \mathrm{true}$.

**Conclusion.**

$$\mathrm{verifyTaprootCommitment}\big(\mathrm{control},\; q,\; \mathrm{tapleafHash}(\langle \mathrm{control}_0 \,\&\, \texttt{0xfe}\rangle_8,\ \mathrm{script})\big) = \mathrm{true},$$

where $\mathrm{control}_0$ is the first byte of $\mathrm{control}$ as a natural (default $0$ if $\mathrm{control}$ is empty), $\&$ is bitwise AND, $\langle\cdot\rangle_8$ converts a natural to an 8-bit value (mod $256$), and $\mathrm{tapleafHash}(v, s) = \mathrm{tagged}(\texttt{"TapLeaf"}, [v] \,\Vert\, \mathrm{CompactSize}(|s|) \,\Vert\, s)$.

**$\mathrm{verifyTaprootCommitment}$, unfolded.** $\mathrm{verifyTaprootCommitment}(\mathrm{control}, q, \ell) = \mathrm{checkTapTweak}\big(q,\ \mathrm{control}[1{:}33],\ \mathrm{taprootMerkleRoot}(\mathrm{control}, \ell),\ [\mathrm{control}_0 \text{ is odd}]\big)$, where $\mathrm{control}[1{:}33]$ is "drop the first byte, then take up to $32$ bytes" (shorter if $\mathrm{control}$ is shorter than $33$ bytes), and the parity bit is the low bit of the first control byte (default $0$). $\mathrm{taprootMerkleRoot}(\mathrm{control}, \ell)$ is the left fold $h_0 = \ell$, $h_{j+1} = \mathrm{tapbranchHash}(h_j, N_j)$ over the $k = \lfloor(|\mathrm{control}| \dot- 33)/32\rfloor$ consecutive $32$-byte chunks $N_j$ of $\mathrm{control}$ after its first $33$ bytes; $\mathrm{tapbranchHash}(x,y) = \mathrm{tagged}(\texttt{"TapBranch"}, \min_{\mathrm{lex}}(x,y) \Vert \max_{\mathrm{lex}}(x,y))$ with the file's lexicographic order (ties concatenate $y \Vert x$, which equals $x \Vert y$). $\mathrm{checkTapTweak}(q, \mathrm{int}, m, \pi)$ is: let $P := \mathrm{liftX}(\mathrm{BE}(\mathrm{int}))$ — $\mathrm{none}$ if $\mathrm{BE}(\mathrm{int}) \ge p$ or if $x^3+7$ is not a square mod $p$, else the point with abscissa $x = \mathrm{BE}(\mathrm{int})$ and even ordinate; $\mathrm{false}$ if $P$ is $\mathrm{none}$; otherwise $\mathrm{xonlyTweakAddCheck}(q, \pi, P, \mathrm{tapTweakHash}(\mathrm{int}, m))$, where $\mathrm{tapTweakHash}(\mathrm{int}, m) = \mathrm{tagged}(\texttt{"TapTweak"}, \mathrm{int} \Vert m)$, and $\mathrm{xonlyTweakAddCheck}(q, \pi, P, T)$ is: let $t := \mathrm{BE}(T)$; $\mathrm{false}$ if $n \le t$; let $Q := P + t\cdot G$ (bundle's affine formulas, $t \cdot G$ being $\mathrm{none}$ when $t = 0$ so that $Q = P$); $\mathrm{false}$ if $Q$ is the point at infinity; else $\mathrm{true}$ iff the 32-byte big-endian encoding of $x_Q \bmod 2^{256}$ equals $q$ and ($y_Q$ is odd) $= \pi$. $\mathrm{tagged}(T, m) = \mathrm{SHA256}(\mathrm{SHA256}(T)\Vert\mathrm{SHA256}(T)\Vert m)$, $T$ the UTF-8 bytes of the tag.

**Hypothesis 2, unfolded.** $\mathrm{taprootHandler}(\mathrm{spent})(c, W, q)$: $W$ is non-empty; by hypothesis 1 there is no annex, so the working stack is $W$ itself; its length is $|\mathrm{stack}| + 2 \ne 1$, so the key path is not taken. The script path pops the last element as the control block ($= \mathrm{control}$), then the last remaining element as the script ($= \mathrm{script}$), leaving $\mathrm{stack}$. It returns $\mathrm{false}$ if $|\mathrm{control}| < 33$, or $|\mathrm{control}| > 4129$ ($= 33 + 32 \cdot 128$), or $(|\mathrm{control}| - 33) \bmod 32 \neq 0$. Otherwise, with leaf version $v := \mathrm{control}_0 \,\&\, \texttt{0xfe}$ and $\ell := \mathrm{tapleafHash}(\langle v \rangle_8, \mathrm{script})$, it returns $\mathrm{false}$ if $\mathrm{verifyTaprootCommitment}(\mathrm{control}, q, \ell)$ is $\mathrm{false}$; otherwise, if $v = \texttt{0xc0}$ it returns $\mathrm{executeTapscript}$ of the Tapscript context (flags `cltv`, `csv`, `nulldummy` from $c.\mathrm{flags}$, $c.\mathrm{tx}$, $\mathrm{spent}$, $c.\mathrm{nIn}$), the `ExecData` $(\mathrm{false}, [\,], \ell, \texttt{0xFFFFFFFF})$, the reversed $\mathrm{stack}$, $\mathrm{script}$, and the initial weight (serialized size of the whole witness $W$ as a CompactSize-prefixed list of CompactSize-prefixed elements) $+ 50$; and if $v \neq \texttt{0xc0}$ it returns $\mathrm{true}$. Hence hypothesis 2 entails that the size checks pass and that the commitment check in the conclusion evaluates to $\mathrm{true}$ (plus either successful Tapscript execution or an unknown leaf version), and the theorem extracts the commitment part.

**Edge cases the quantifiers include.** $\mathrm{stack} = [\,]$ (witness of exactly two elements); $\mathrm{control}$ empty or shorter than $33$ bytes — then hypothesis 2 is false and the statement is vacuous for those; $\mathrm{control}$ with first byte $\texttt{0x50}$ is excluded by hypothesis 1 (first byte $\texttt{0x51}$ is allowed, giving the same leaf version $\texttt{0x50}$); $q$ of length $\neq 32$ makes the commitment false, hence hypothesis 2 false; leaf versions other than $\texttt{0xc0}$, where hypothesis 2 reduces to the size and commitment checks alone; $\mathrm{script}$ empty; $c.\mathrm{flags}.\mathrm{taproot}$ and $c.\mathrm{amount}$ unused.
