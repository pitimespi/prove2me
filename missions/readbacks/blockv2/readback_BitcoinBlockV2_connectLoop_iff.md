# Read-back: `BitcoinBlockV2.connectLoop_iff`

**Binders.** $f$ is a script-flag record (seven Booleans: p2sh, witness, taproot, dersig, cltv, csv, nulldummy); $H$ is a natural number (the height); $\mathit{mtp} : \mathbb{N} \to \mathbb{N}$ is an arbitrary function; $\mathit{ltf}$ is a natural number (lock-time flags); $\mathit{txs}$ is a list of transactions; $u$ is a ledger; $\mathit{fees}$ is an integer; $\mathit{sigOps}$ is a natural number; $\mathit{undo}$ is a block undo (list of lists of coins).

**Hypotheses.**
- $h_{pos}$: for every $tx \in \mathit{txs}$, $0 \le \mathrm{valueOut}(tx)$ (sum of its output values).
- $h_{fees}$: $0 \le \mathit{fees}$.

Both are carried; the equivalence below does not mention them.

**Conclusion.** The following are equivalent:

*Left:* there exists a loop state $\mathit{st}$ with $\mathrm{connectLoop}(f, H, \mathit{mtp}, \mathit{ltf}, (u, \mathit{fees}, \mathit{sigOps}, \mathit{undo}), \mathit{txs}) = \mathrm{some}(\mathit{st})$. Unfolding: the loop processes $\mathit{txs}$ in order with state $(u', F, \sigma, U)$ starting at $(u, \mathit{fees}, \mathit{sigOps}, \mathit{undo})$ and succeeds on the empty list. For $tx$: if $\mathrm{isCoinBase}(tx)$ (exactly one input, null prevout) the step yields $(F, U)$; otherwise $\mathrm{checkTxInputs}(u', tx, H)$ must be $\mathrm{some}(\mathit{fee})$ (every prevout has a coin; the input loop — maturity $H \mathbin{\dot-} c.\mathit{height} \ge 100$ for coinbase coins, each value and running total in $[0,\mathrm{MAX\_MONEY}]$ — succeeds with $V_{in}$; $V_{in} \ge \mathrm{valueOut}(tx)$; $V_{in} - \mathrm{valueOut}(tx) \in [0,\mathrm{MAX\_MONEY}]$), $F + \mathit{fee} \in [0, \mathrm{MAX\_MONEY}]$, and $\mathrm{sequenceLocksOk}(u', H, \mathit{mtp}, \mathit{ltf}, tx)$ (the imperative BIP68 `sequenceLocks` on $(\mathit{version}(tx) \bmod 2^{32}, \mathit{ltf} \bmod 2^{32})$, context $(H, \mathit{mtp})$ and the inputs' (sequence, coin height) pairs with missing coins at height $0$), yielding $(F + \mathit{fee}, U \mathbin{+\!\!+} [\text{coins spent by } tx])$. Then $\sigma' = \sigma + \mathrm{txSigOpCost}(f, u', tx)$ must satisfy $\sigma' \le 80\,000$, a non-coinbase must satisfy $\mathrm{inputScriptsOk}(f, u', tx)$ (every input verifies under `verifyScriptFull`), and the loop continues with $(\mathrm{updateCoins}(u', tx, H), F', \sigma', U')$.

*Right:* $\mathrm{TxsSpec}(f, H, \mathit{mtp}, \mathit{ltf}, u, \mathit{fees}, \mathit{sigOps}, \mathit{txs})$: true for the empty list; for $tx :: \mathit{rest}$ with current $(u', F, \sigma)$:
$$\big(\mathrm{isCoinBase}(tx) = \mathrm{false} \to \mathrm{TxInputsSpec}(f, u', H, \mathit{mtp}, \mathit{ltf}, tx) \land F + \mathrm{feeOf}(u', tx) \le \mathrm{MAX\_MONEY}\big) \land \sigma + \mathrm{txSigOpCost}(f, u', tx) \le 80\,000$$
and recursively on $\mathit{rest}$ with $(\mathrm{updateCoins}(u', tx, H),\ F \text{ if coinbase else } F + \mathrm{feeOf}(u', tx),\ \sigma + \mathrm{txSigOpCost}(f, u', tx))$. $\mathrm{TxInputsSpec}$ is: every input has a coin $c$ in $u'$ with ($c.\mathit{isCoinbase} \to c.\mathit{height} + 100 \le H$) and $0 \le c.\mathit{out}.\mathit{nValue} \le \mathrm{MAX\_MONEY}$; $\mathrm{valueIn}(u', \mathit{vin}(tx)) \le \mathrm{MAX\_MONEY}$; $\mathrm{valueOut}(tx) \le \mathrm{valueIn}(u', \mathit{vin}(tx))$; `satisfiesBIP68` (the declarative BIP68 predicate: not enabled, or every input disabled or satisfied) on the same data as the left; and for every $n < |\mathit{vin}(tx)|$, `verifyScriptFull` returns true for input $n$. $\mathrm{feeOf}(u', tx) = \mathrm{valueIn}(u', \mathit{vin}(tx)) - \mathrm{valueOut}(tx)$.

**Edge cases silently included:** $\mathit{undo}$ appears only on the left (it is threaded, never tested); the hypotheses $h_{pos}$, $h_{fees}$ are absent from the equivalence; $\mathrm{TxsSpec}$ has no lower bound on $F + \mathrm{feeOf}$ whereas the loop requires $F + \mathit{fee} \ge 0$; coinbase transactions anywhere in the list; empty input lists (vacuous `TxInputsSpec` clauses, `checkTxInputs` succeeding with fee $-\mathrm{valueOut}$ when in range); the left uses `sequenceLocks` and the right `satisfiesBIP68`; $\mathit{mtp}$ is an arbitrary function, with $\mathit{mtp}(0 \mathbin{\dot-} 1) = \mathit{mtp}(0)$.
