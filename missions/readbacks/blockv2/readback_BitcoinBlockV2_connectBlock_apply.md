# Read-back: `BitcoinBlockV2.connectBlock_apply`

**Binders.** $S$ is a chain state (a list of headers and a ledger $S.\mathit{utxo}$); $b$ is a block; $u$ is a ledger; $\mathit{undo}$ is a block undo (a list of lists of coins).

**Hypothesis.** $h$: $\mathrm{connectBlock}(S, b) = \mathrm{some}(u, \mathit{undo})$. Unfolding $\mathrm{connectBlock}$ with $\mathit{hash} = \mathrm{headerHash}(b.\mathit{header})$ and $\mathit{height} = |S.\mathit{headers}|$: either $\mathit{hash}$ equals the fixed literal `genesisHash` and then $(u, \mathit{undo}) = (S.\mathit{utxo}, [\,])$; or $\mathit{hash}$ is not the genesis hash, it is not the case that ($\mathrm{bip30Checked}(S, \mathit{height}, \mathit{hash})$ and some output of some transaction of $b$ already has a coin in $S.\mathit{utxo}$), the transaction loop $\mathrm{connectLoop}$ with flags `blockScriptFlags`$(\mathit{height}, \mathrm{scriptException}(\mathit{hash}))$, height $\mathit{height}$, median-time function $S.\mathrm{mtpNat}$, lock-time flags ($1$ if $419328 \le \mathit{height}$ else $0$), from state $(S.\mathit{utxo}, 0, 0, [\,])$ over $b.\mathit{vtx}$ returns a final state $\mathit{st}$ (each non-coinbase passing `checkTxInputs`, fee range, `sequenceLocksOk`, the running sigop budget $\le 80\,000$ and `inputScriptsOk`; each coinbase passing only the sigop budget; the ledger advanced by `updateCoins` after each transaction), the first transaction's output value is $\le \mathit{st}.\mathit{fees} + \mathrm{coreSubsidy}(\mathit{height})$, and $(u, \mathit{undo}) = (\mathit{st}.\mathit{utxo}, \mathit{st}.\mathit{undo})$. The value $\mathit{undo}$ is not used in the conclusion.

**Conclusion.** $u = (\mathrm{applySpec}(S, b)).\mathit{utxo}$, i.e.
$$u = \begin{cases} S.\mathit{utxo} & \text{if } \mathrm{headerHash}(b.\mathit{header}) = \mathrm{genesisHash},\\ \mathrm{applyTxs}(|S.\mathit{headers}|, S.\mathit{utxo}, b.\mathit{vtx}) & \text{otherwise}, \end{cases}$$
where $\mathrm{applyTxs}$ is the left fold of $\mathrm{updateCoins}(\cdot, tx, |S.\mathit{headers}|)$ over the transactions in order; $\mathrm{updateCoins}(u, tx, H)$ removes every entry keyed by a prevout of $tx$ (unless $tx$ is a coinbase), then for each output $o_j$ whose scriptPubKey neither starts with $\mathtt{0x6a}$ nor exceeds $10\,000$ bytes removes any entry keyed $(\mathrm{txid}(tx), j)$ and prepends $((\mathrm{txid}(tx), j), (o_j, H, \mathrm{isCoinBase}(tx)))$. The equality is equality of lists (entries and order).

**Edge cases silently included:** the genesis short-circuit; an empty transaction list (loop returns the initial state, first transaction defaults to the genesis coinbase for the subsidy bound); $\mathit{undo}$ unused; the hypothesis may be unsatisfiable for the given $S, b$, making the statement vacuous.
