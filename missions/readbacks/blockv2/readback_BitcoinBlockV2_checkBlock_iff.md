# Read-back: `BitcoinBlockV2.checkBlock_iff`

**Binder.** $b$ is a block: a header $b.\mathit{header}$ (integer version, byte strings $\mathit{prevBlock}$, $\mathit{merkleRoot}$, naturals $\mathit{time}$, $\mathit{bits}$, $\mathit{nonce}$) and a list of transactions $b.\mathit{vtx}$. No hypotheses.

**Conclusion.** $\mathrm{checkBlock}(b) = \mathrm{true}$ if and only if $\mathrm{checkHeaderPow}(b.\mathit{header}) = \mathrm{true}$ and $\mathrm{BlockSpec}(b)$.

*Left side unfolded.* $\mathrm{checkBlock}(b)$ is the conjunction of: $\mathrm{checkHeaderPow}(b.\mathit{header})$; the merkle root computed from the txids of $b.\mathit{vtx}$ equals $b.\mathit{header}.\mathit{merkleRoot}$; the mutation flag of that computation is false; $b.\mathit{vtx}$ is non-empty; $4\cdot|b.\mathit{vtx}| \le 4\,000\,000$; $4\cdot|\mathrm{serBlock}(\mathrm{false}, b)| \le 4\,000\,000$ (witness-stripped serialization: header bytes, compact-size count, then each transaction stripped); the first transaction of $b.\mathit{vtx}$ — defaulting to the genesis coinbase when the list is empty — is a coinbase (exactly one input, whose prevout is 32 zero bytes with index $\mathtt{0xffffffff}$); every transaction after the first is not a coinbase; every transaction passes $\mathrm{checkTransaction}$ (non-empty inputs, non-empty outputs, $4\cdot$stripped size $\le 4\,000\,000$, the output loop succeeds — each value in $[0, \mathrm{MAX\_MONEY}]$ and each running total in $[0, \mathrm{MAX\_MONEY}]$ —, distinct prevouts, and for a coinbase the *first* input's scriptSig length is in $[2, 100]$ while for a non-coinbase every prevout is non-null); and $4\cdot\sum_{tx} \mathrm{legacySigOpCount}(tx) \le 80\,000$, where the legacy count sums, over every input's scriptSig and every output's scriptPubKey, the number of `OP_CHECKSIG`/`OP_CHECKSIGVERIFY` opcodes plus $20$ per `OP_CHECKMULTISIG`/`OP_CHECKMULTISIGVERIFY`, stopping at the first unparsable instruction.

*Right side unfolded.* $\mathrm{checkHeaderPow}(b.\mathit{header})$: the compact word $b.\mathit{header}.\mathit{bits} \bmod 2^{32}$ decodes to a target $t$ (not negative, non-zero, not overflowing, $t \le 2^{224}-1$, computed with truncation modulo $2^{256}$) and the little-endian value of $\mathrm{hash256}$ of the serialized header is $\le t$. $\mathrm{BlockSpec}(b)$ is the proposition: $b.\mathit{vtx} \ne [\,]$; the merkle root equals $b.\mathit{header}.\mathit{merkleRoot}$; the mutation flag equals false; $4|b.\mathit{vtx}| \le 4\,000\,000$; $4|\mathrm{serBlock}(\mathrm{false}, b)| \le 4\,000\,000$; every transaction among the first one is a coinbase; every transaction after the first is not; every transaction satisfies $\mathrm{TxSpec}$ (non-empty inputs and outputs; $4\cdot$stripped size $\le 4\,000\,000$; every output value in $[0,\mathrm{MAX\_MONEY}]$; $\mathrm{valueOut} \le \mathrm{MAX\_MONEY}$; distinct prevouts; if coinbase, every input's scriptSig length in $[2,100]$; if not, every prevout non-null); and $4\sum\mathrm{legacySigOpCount} \le 80\,000$.

**Edge cases silently included:** the `headD` default (genesis coinbase) on the left versus the quantification over `take 1` on the right when $b.\mathit{vtx}$ is empty; the output loop's running-total bound versus $\mathrm{TxSpec}$'s single bound on the final sum; the coinbase scriptSig check on the first input only (left) versus all inputs (right) — a coinbase has exactly one input by definition.
