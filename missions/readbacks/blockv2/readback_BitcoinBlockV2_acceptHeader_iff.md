# Read-back: `BitcoinBlockV2.acceptHeader_iff`

**Binders.** $S$ is a chain state (a pair of a list of headers and a ledger, i.e. a list of (outpoint, coin) pairs); $h$ is a block header (integer $\mathit{version}$, byte strings $\mathit{prevBlock}$ and $\mathit{merkleRoot}$ of unconstrained length, natural numbers $\mathit{time}$, $\mathit{bits}$, $\mathit{nonce}$); $\mathit{now}$ is an integer. There are no hypotheses.

**Conclusion.** The following two statements are equivalent.

*Left side:* $\mathrm{acceptHeader}(S, h, \mathit{now})$ equals the outcome $\mathrm{accept}(S, [\,])$ — the accept constructor carrying exactly the input state $S$ and the empty undo list. Unfolding, $\mathrm{acceptHeader}$ returns, in order, $\mathrm{invalid}$ if $\lnot\mathrm{checkHeaderPow}(h)$; $\mathrm{missingPrev}$ if $h.\mathit{prevBlock} \ne S.\mathrm{tipHash}$; $\mathrm{invalid}$ if $h.\mathit{bits} \bmod 2^{32} \ne S.\mathrm{requiredBits}$ (as 32-bit words); $\mathrm{invalid}$ if $h.\mathit{time} \le S.\mathit{mtp}$; $\mathrm{futureTime}$ if $\mathit{now} + 7200 < h.\mathit{time}$; $\mathrm{invalid}$ if $\mathrm{versionOutdated}(h.\mathit{version}, S.\mathrm{tipHeight})$; and otherwise $\mathrm{accept}(S, [\,])$. So the left side holds exactly when none of the six rejection cases fires.

*Right side:* the conjunction of three conditions:

1. $\mathrm{checkHeaderPow}(h) = \mathrm{true}$: with $c$ the 32-bit word $h.\mathit{bits} \bmod 2^{32}$, the compact target decodes (`deriveTarget`): $c$ is not negative (not both mantissa $c \mathbin{\&}\mathtt{0x7fffff} \ne 0$ and bit $\mathtt{0x800000}$ set), the decoded value $t$ (mantissa shifted by $8(e-3)$ bits, truncated modulo $2^{256}$, with $e = c \gg 24$) is non-zero, $c$ does not overflow, and $t \le 2^{224}-1$; and the little-endian integer value of $\mathrm{hash256}$ of the serialized header is $\le t$.
2. $h.\mathit{prevBlock} = S.\mathrm{tipHash}$, where $S.\mathrm{tipHash}$ is $\mathrm{hash256}$ of the serialization of the last header of $S.\mathit{headers}$ (or of the genesis header if that list is empty).
3. `BitcoinHeader.contextualCheck` applied to the reduced header $(h.\mathit{version}, h.\mathit{time} \text{ as an integer}, h.\mathit{bits} \bmod 2^{32})$, the previous height $S.\mathrm{tipHeight} = |S.\mathit{headers}| \mathbin{\dot-} 1$, the time list $S.\mathrm{timesTo}(S.\mathrm{tipHeight})$ (the times of the first $\mathrm{tipHeight}+1$ headers, most recent first), the required word $S.\mathrm{requiredBits}$ and $\mathit{now}$ returns true. That imported function is the conjunction of: $h.\mathit{bits} \bmod 2^{32} = S.\mathrm{requiredBits}$; $\mathrm{medianTimePast}(S.\mathrm{timesTo}(S.\mathrm{tipHeight})) < h.\mathit{time}$, where the median is the element at index $\lfloor \ell/2\rfloor$ of the ascending sort of the first $\le 11$ times ($\ell$ their count; $0$ for an empty window) — this quantity is by definition $S.\mathit{mtp}$; $h.\mathit{time} \le \mathit{now} + 7200$; and not $\big((h.\mathit{version} < 2 \land 227931 \le S.\mathrm{tipHeight}+1) \lor (h.\mathit{version} < 3 \land 363725 \le S.\mathrm{tipHeight}+1) \lor (h.\mathit{version} < 4 \land 388381 \le S.\mathrm{tipHeight}+1)\big)$.

Here $S.\mathrm{requiredBits}$ is `BitcoinPow.nextWorkRequired` of the tip height, the tip's bits as a 32-bit word, the tip's time and the time of the header at index $S.\mathrm{tipHeight} \mathbin{\dot-} 2015$ (genesis header if out of range): the tip's bits unless $(\mathrm{tipHeight}+1) \bmod 2016 = 0$, in which case the retargeted compact word.

**Edge cases silently included:** an empty header list ($\mathrm{tipHeight} = 0$, tip = genesis header, median $0$); $\mathit{bits}$, $\mathit{time}$ and $\mathit{prevBlock}$ unconstrained in size (only $\mathit{bits}$ is reduced mod $2^{32}$); the truncated subtraction in the retarget index; the equivalence says nothing about which rejection outcome is produced when the right side fails.
