# Read-back: `BitcoinBlockV2.disconnect_connect`

**Binders.** $S$ and $S'$ are chain states (each a list of headers and a ledger, i.e. a list of (outpoint, coin) pairs with a coin being an output, a natural height and a coinbase flag); $b$ is a block; $\mathit{now}$ is an integer; $\mathit{undo}$ is a block undo (list of lists of coins).

**Hypotheses.**
- $h_{wf}$: $\mathrm{WellFormed}(S)$ — the first element of $S.\mathit{headers}$ exists and equals the genesis header; the keys of $S.\mathit{utxo}$ are pairwise distinct; every entry $e$ of $S.\mathit{utxo}$ has $1 \le e.2.\mathit{height} \le S.\mathrm{tipHeight}$ ($= |S.\mathit{headers}| \mathbin{\dot-} 1$) and its scriptPubKey is not unspendable (does not start with $\mathtt{0x6a}$ and has length $\le 10\,000$).
- $h_{nd}$: the list $[\mathrm{txid}(tx) \mid tx \in b.\mathit{vtx}]$ has no duplicates.
- $h_{fresh}$: for every $tx \in b.\mathit{vtx}$ and **every** natural number $o$ (not only $o < |\mathit{vout}(tx)|$), $\mathrm{getCoin}(S.\mathit{utxo}, (\mathrm{txid}(tx), o)) = \mathrm{none}$.
- $h_g$: $\mathrm{headerHash}(b.\mathit{header}) \ne \mathrm{genesisHash}$.
- $h$: $\mathrm{validate}(S, b, \mathit{now}) = \mathrm{accept}(S', \mathit{undo})$ — the header is accepted on top of $S$'s tip at clock $\mathit{now}$, $\mathrm{checkBlock}(b)$ and $\mathrm{contextualCheckBlock}(S, b)$ hold, and $\mathrm{connectBlock}(S, b) = \mathrm{some}(u', \mathit{undo})$ with $S' = (S.\mathit{headers} \mathbin{+\!\!+} [b.\mathit{header}], u')$; given $h_g$, $\mathit{undo}$ is the list, in block order, of one coin list per non-coinbase transaction, each listing (via `accessCoin` on the ledger at that point) the coins its inputs spent, and $u'$ is the ledger after `updateCoins` for every transaction.

**Conclusion.** There exists a ledger $u$ such that
$$\mathrm{disconnectBlock}(S'.\mathit{utxo},\ |S.\mathit{headers}|,\ \mathrm{headerHash}(b.\mathit{header}),\ b,\ \mathit{undo}) = \mathrm{some}(u, \mathrm{true}) \quad\text{and}\quad \mathrm{Equiv}(u, S.\mathit{utxo}),$$
where $\mathrm{Equiv}(u, v)$ means $\forall \mathit{op},\ \mathrm{getCoin}(u, \mathit{op}) = \mathrm{getCoin}(v, \mathit{op})$ (first-match lookups agree on every outpoint; list order and duplicate entries are not compared).

Unfolding $\mathrm{disconnectBlock}(u_0, H, \mathit{hash}, b, \mathit{undo})$: it is none if $|\mathit{undo}| + 1 \ne |b.\mathit{vtx}|$; otherwise it pairs the transactions with $\mathrm{none} :: [\mathrm{some}(c) \mid c \in \mathit{undo}]$, reverses that list, and processes the pairs in that order with $\mathrm{disconnectTx}$, threading the ledger and conjoining "clean" flags, with $\mathit{exception} = \mathrm{isBIP30Unspendable}(H, \mathit{hash})$ ($H \in \{91722, 91812\}$ with the matching literal hash). $\mathrm{disconnectTx}$ on $(tx, \mathit{undo}_{tx})$: first $\mathrm{spendOutputs}$ — for each output $o_j$ of $tx$ that is not unspendable, the flag for this output is "the ledger has a coin at $(\mathrm{txid}(tx), j)$ equal to $(o_j, H, \mathrm{isCoinBase}(tx))$" or ($\mathrm{isCoinBase}(tx) \land \mathit{exception}$), and the entry at $(\mathrm{txid}(tx), j)$ is removed; unspendable outputs are skipped and clean. Then if $\mathit{undo}_{tx}$ is $\mathrm{some}(\mathit{coins})$: none if $|\mathit{coins}| \ne |\mathit{vin}(tx)|$, else $\mathrm{restoreInputs}$ processes the (input, coin) pairs from the last to the first, each via $\mathrm{applyTxInUndo}$: clean iff no coin is currently at the prevout; if the undo coin has height $0$ its height and coinbase flag are taken from the first ledger entry whose key has the same transaction hash (none if there is no such entry, which fails the whole disconnect); then $\mathrm{addCoin}$ at the prevout (no-op if the coin's script is unspendable). The result $\mathrm{some}(u, \mathrm{true})$ requires every per-output and per-input flag to be true.

**Edge cases silently included:** $\mathit{now}$ appears only in $h$; $h_{fresh}$ quantifies over all output indices; $h_{wf}$ and $h_{nd}$ are hypotheses whose use is not visible in the conclusion; undo coins with height $0$ trigger the same-hash lookup; `Equiv` ignores ordering and duplicates; coins of unspendable outputs are never stored and never restored.
