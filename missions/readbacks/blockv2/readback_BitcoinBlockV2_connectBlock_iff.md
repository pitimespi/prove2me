# Read-back: `BitcoinBlockV2.connectBlock_iff`

**Binders.** $S$ is a chain state (a list of headers and a ledger); $b$ is a block.

**Hypotheses.**
- $h_{ne}$: $b.\mathit{vtx} \ne [\,]$ — the block has at least one transaction.
- $h_{pos}$: for every transaction $tx$ in $b.\mathit{vtx}$, $0 \le \mathrm{valueOut}(tx)$, where $\mathrm{valueOut}(tx)$ is the integer sum of the $\mathit{nValue}$ fields of its outputs.

Both hypotheses are carried in the statement; the equivalence below does not mention them.

**Conclusion.** The following are equivalent:

*Left:* there exists $r$ (a pair of a ledger and a block undo) with $\mathrm{connectBlock}(S, b) = \mathrm{some}(r)$. Unfolding, with $\mathit{hash} = \mathrm{headerHash}(b.\mathit{header})$, $\mathit{height} = |S.\mathit{headers}|$: either $\mathit{hash} = \mathrm{genesisHash}$ (then the result is $\mathrm{some}(S.\mathit{utxo}, [\,])$ unconditionally); or not ($\mathrm{bip30Checked}(S, \mathit{height}, \mathit{hash})$ and some $(\mathrm{txid}(tx), o)$ with $o < |\mathit{vout}(tx)|$ already has a coin in $S.\mathit{utxo}$), and $\mathrm{connectLoop}(\mathit{flags}, \mathit{height}, S.\mathrm{mtpNat}, \mathit{ltf}, (S.\mathit{utxo}, 0, 0, [\,]), b.\mathit{vtx})$ returns some state $\mathit{st}$, and $\lnot\big(\mathrm{valueOut}(tx_0) > \mathit{st}.\mathit{fees} + \mathrm{coreSubsidy}(\mathit{height})\big)$ for the first transaction $tx_0$; here $\mathit{flags} = $ `blockScriptFlags`$(\mathit{height}, \mathrm{scriptException}(\mathit{hash}))$, $\mathit{ltf} = 1$ if $419328 \le \mathit{height}$ else $0$, and $\mathrm{coreSubsidy}(\mathit{height}) = 5\cdot10^9 \gg \lfloor\mathit{height}/210000\rfloor$ (and $0$ once that quotient is $\ge 64$). The loop, per transaction $tx$ with current ledger $u$: if coinbase, fees and undo unchanged; else `checkTxInputs`$(u, tx, \mathit{height})$ must yield a fee, $\mathit{fees} + \mathit{fee} \in [0, \mathrm{MAX\_MONEY}]$, `sequenceLocksOk` must hold, and the undo list is extended by the coins spent; then the running sigop cost (plus `txSigOpCost`$(\mathit{flags}, u, tx)$) must be $\le 80\,000$, every input script of a non-coinbase must verify (`inputScriptsOk`), and the ledger becomes `updateCoins`$(u, tx, \mathit{height})$.

*Right:* $\mathrm{LedgerSpec}(S, b)$: $\mathit{hash} = \mathrm{genesisHash}$, **or** all three of
1. $\mathrm{bip30Checked}(S, \mathit{height}, \mathit{hash}) = \mathrm{true} \to \forall tx \in b.\mathit{vtx},\ \forall o < |\mathit{vout}(tx)|,\ \mathrm{getCoin}(S.\mathit{utxo}, (\mathrm{txid}(tx), o)) = \mathrm{none}$, where $\mathrm{bip30Checked}$ is $(\lnot\mathrm{isBIP30Repeat}(\mathit{height}, \mathit{hash}) \land \lnot(\text{the header at index }227931\text{ of }S.\mathit{headers}\text{ exists and hashes to `bip34Hash'})) \lor 1983702 \le \mathit{height}$;
2. $\mathrm{TxsSpec}(\mathit{flags}, \mathit{height}, S.\mathrm{mtpNat}, \mathit{ltf}, S.\mathit{utxo}, 0, 0, b.\mathit{vtx})$: processing the transactions in order with running ledger $u$ (initially $S.\mathit{utxo}$), fees $F$ (initially $0$) and sigops $\sigma$ (initially $0$): for each $tx$, (if $tx$ is not a coinbase then $\mathrm{TxInputsSpec}(\mathit{flags}, u, \mathit{height}, S.\mathrm{mtpNat}, \mathit{ltf}, tx)$ — every input has an existing coin $c$ with ($c$ coinbase $\to c.\mathit{height}+100 \le \mathit{height}$) and value in $[0,\mathrm{MAX\_MONEY}]$; $\mathrm{valueIn} \le \mathrm{MAX\_MONEY}$; $\mathrm{valueOut} \le \mathrm{valueIn}$; `satisfiesBIP68` on the inputs' sequences and coin heights; every input script verifies via `verifyScriptFull` — and $F + \mathrm{feeOf}(u, tx) \le \mathrm{MAX\_MONEY}$), and $\sigma + \mathrm{txSigOpCost}(\mathit{flags}, u, tx) \le 80\,000$; then $u := \mathrm{updateCoins}(u, tx, \mathit{height})$, $F := F$ if coinbase else $F + \mathrm{feeOf}(u, tx)$, $\sigma := \sigma + \mathrm{txSigOpCost}$;
3. for every $cb$ among the first transaction, $\mathrm{valueOut}(cb) \le \mathrm{totalFees}(\mathit{height}, S.\mathit{utxo}, b.\mathit{vtx}) + \mathrm{specSubsidy}(\mathit{height})$, where $\mathrm{totalFees}$ sums $\mathrm{feeOf}$ of each non-coinbase against the running ledger and $\mathrm{specSubsidy}(\mathit{height}) = \lfloor 5\cdot 10^9 / 2^{\lfloor\mathit{height}/210000\rfloor}\rfloor$.

**Edge cases silently included:** the hypotheses $h_{ne}$, $h_{pos}$ do not appear in the equivalence; the genesis-hash disjunct on both sides; coinbase transactions at positions other than the first are handled by the coinbase branch on both sides; the left uses `coreSubsidy` and the right `specSubsidy`; $S.\mathrm{mtpNat}$ clamps negative medians to $0$; missing coins read as value $-1$, height $0$ through `accessCoin` in `valueIn`, the BIP68 inputs and the sigop count.
