# Read-back: `BitcoinToLocal.p2wsh_spend`

**Statement.** Let

- $\mathrm{tap}$ be a *Taproot handler*: an arbitrary function taking a verification context, a list of byte strings and a byte string to a boolean (nothing is assumed about it);
- $c$ be a *verification context*: a record $(c.\mathrm{flags}, c.\mathrm{tx}, c.n_{\mathrm{in}}, c.\mathrm{amount})$ where $c.\mathrm{flags}$ is a consensus flag record of seven booleans $(\mathrm{p2sh}, \mathrm{witness}, \mathrm{taproot}, \mathrm{dersig}, \mathrm{cltv}, \mathrm{csv}, \mathrm{nulldummy})$, $c.\mathrm{tx}$ a transaction (record of $\mathrm{version} \in \mathbb{N}$, a list $\mathrm{vin}$ of inputs each with $\mathrm{prevout}$, $\mathrm{scriptSig}$, $\mathrm{nSequence} \in \mathbb{N}$, $\mathrm{witness}$; a list $\mathrm{vout}$ of outputs each with $\mathrm{nValue} \in \mathbb{Z}$ and $\mathrm{scriptPubKey}$; and $\mathrm{nLockTime} \in \mathbb{N}$), $c.n_{\mathrm{in}} \in \mathbb{N}$ and $c.\mathrm{amount} \in \mathbb{Z}$;
- the hypothesis $c.\mathrm{flags}.\mathrm{witness} = \mathrm{true}$ hold;
- $R$ (`rev`), $D$ (`dpk`) be byte strings, $\delta \in \mathbb{Z}$ (`delay`), and $\mathrm{ws}$ a list of byte strings;
- $|R| \le 520$, $|D| \le 520$ and $|\delta| < 2^{32}$ ($|\delta|$ the absolute value as a natural; $520$ is `MAX_SCRIPT_ELEMENT_SIZE`).

Write $W := \mathrm{toLocalBytes}(R, \delta, D)$ for the serialized witness script and $H := \mathrm{sha256}(W)$ for its digest under the preamble's SHA-256 implementation (a 32-byte string: eight big-endian 32-bit words). Then

$$
\mathrm{verifyScript}\big(\mathrm{tap},\ c,\ [\,],\ \mathrm{witnessBytes}(0, H),\ \mathrm{ws} \mathbin{+\!\!+} [W]\big) = \mathrm{true}
\iff
\mathrm{castToBool}(H) = \mathrm{true}\ \land\ \exists\, b\ \mathrm{sig}.\ \Big( \mathrm{ws} = [\mathrm{sig}, b]\ \land\ |\mathrm{sig}| \le 520\ \land\ |b| \le 520\ \land\ \mathrm{SpendCondition}\big(\varphi,\ \omega,\ R, \delta, D, b, \mathrm{sig}\big) \Big),
$$

where

$$
\varphi := \mathrm{scriptFlagsOf}(c.\mathrm{flags}) = (c.\mathrm{flags}.\mathrm{cltv},\ c.\mathrm{flags}.\mathrm{csv},\ c.\mathrm{flags}.\mathrm{nulldummy}),
\qquad
\omega := \mathrm{legacyOracle}\big(\mathrm{sigFlagsOf}(c.\mathrm{flags}),\ c.\mathrm{tx},\ c.n_{\mathrm{in}},\ c.\mathrm{amount},\ \mathrm{witnessV0},\ W\big),
$$

and $\mathrm{sigFlagsOf}(c.\mathrm{flags}) = (\mathrm{dersig} = c.\mathrm{flags}.\mathrm{dersig},\ \mathrm{lowS} = \mathrm{false},\ \mathrm{strictenc} = \mathrm{false},\ \mathrm{witnessPubkeyType} = \mathrm{false})$. On the right, $b$ and $\mathrm{sig}$ range over byte strings, and $\mathrm{ws} = [\mathrm{sig}, b]$ says the list $\mathrm{ws}$ has exactly two elements, $\mathrm{sig}$ first and $b$ second (so the full witness list passed on the left is $[\mathrm{sig}, b, W]$).

**The inputs on the left.** The script-signature argument is the empty byte string $[\,]$. The output script is $\mathrm{witnessBytes}(0, H) = \mathtt{0x00} :: \mathrm{pushBytes}(H)$, where $\mathrm{pushBytes}(d)$ for $|d| < 76$ is the byte $|d|$ followed by $d$; for $|H| = 32$ this is the 34-byte string $[\mathtt{0x00}, \mathtt{0x20}] \mathbin{+\!\!+} H$. The witness argument is $\mathrm{ws}$ followed by the single extra element $W$, and

$$
W = [\mathtt{0x63}] \mathbin{+\!\!+} \mathrm{pushBytes}(R) \mathbin{+\!\!+} [\mathtt{0x67}] \mathbin{+\!\!+} \mathrm{numBytes}(\delta) \mathbin{+\!\!+} [\mathtt{0xb2}, \mathtt{0x75}] \mathbin{+\!\!+} \mathrm{pushBytes}(D) \mathbin{+\!\!+} [\mathtt{0x68}, \mathtt{0xac}],
$$

with $\mathrm{pushBytes}(d)$ using the prefixes: byte $|d|$ if $|d| < 76$; $\mathtt{0x4c}, |d|$ if $|d| \le 255$; $\mathtt{0x4d}$ and 2-byte little-endian $|d|$ if $|d| \le 65535$; $\mathtt{0x4e}$ and 4-byte little-endian $|d|$ otherwise; and $\mathrm{numBytes}(\delta)$ the single byte $\delta + 80$ when $\delta = -1$ or $1 \le \delta \le 16$, else $\mathrm{pushBytes}(\mathrm{serialize}(\delta))$ ($\mathrm{serialize}(0) = [\,]$, so $\mathrm{numBytes}(0) = [\mathtt{0x00}]$; otherwise the little-endian magnitude of $|\delta|$ without trailing zeros, with an appended $\mathtt{0x80}$/$\mathtt{0x00}$ byte when the top bit of the last byte is set, else the top bit set on the last byte when $\delta<0$).

**Unfolding `verifyScript`.** $\mathrm{verifyScript}(\mathrm{tap}, c, \mathrm{scriptSig}, \mathrm{scriptPubKey}, \mathrm{witness})$ is the boolean computed as follows (all stacks top-first).

1. Evaluate $\mathrm{scriptSig}$ from the empty stack with signature version $\mathrm{base}$ via $\mathrm{evalBytes}$ (below); if it fails, return $\mathrm{false}$; call the resulting stack $S_1$.
2. Evaluate $\mathrm{scriptPubKey}$ from $S_1$ with version $\mathrm{base}$; if it fails, return $\mathrm{false}$; call the result $S_2$.
3. If $\mathrm{topTrue}(S_2)$ is false ($\mathrm{topTrue}$: false on the empty stack, else $\mathrm{castToBool}$ of the top), return $\mathrm{false}$.
4. Since $c.\mathrm{flags}.\mathrm{witness} = \mathrm{true}$, test whether $\mathrm{scriptPubKey}$ is a *witness program*: its length is between $4$ and $42$; its first byte is $0$ or lies in $\mathtt{0x51}$–$\mathtt{0x60}$; and its second byte plus $2$ equals its length. If so, with version $= 0$ when the first byte is $0$ and (first byte $- \mathtt{0x50}$) otherwise, and program $=$ the bytes after the first two: if $\mathrm{scriptSig} \ne [\,]$, return $\mathrm{false}$; otherwise return $\mathrm{verifyWitnessProgram}(\mathrm{tap}, c, \mathrm{witness}, \text{version}, \text{program}, \mathrm{false})$. (If it is not a witness program, the pay-to-script-hash and "no witness allowed" branches follow; they are not reached when the test succeeds.)

$\mathrm{verifyWitnessProgram}$ with version $0$: if the program has length $32$, take the **last** element of $\mathrm{witness}$ (return $\mathrm{false}$ if $\mathrm{witness}$ is empty) as the script $E$; if $\mathrm{sha256}(E) \ne$ program, return $\mathrm{false}$; else return $\mathrm{executeWitnessScriptV0}(c, \text{reverse of } \mathrm{witness} \text{ without its last element}, E)$. (Length $20$ gives the pay-to-witness-public-key-hash branch; any other length gives $\mathrm{false}$.) Here, with $\mathrm{witness} = \mathrm{ws} \mathbin{+\!\!+} [W]$, the last element is $W$ and the remaining stack is the reverse of $\mathrm{ws}$ — so for $\mathrm{ws} = [\mathrm{sig}, b]$ the execution stack is $[b, \mathrm{sig}]$ with $b$ on top.

$\mathrm{executeWitnessScriptV0}(c, \mathrm{stack}, E)$: if any element of $\mathrm{stack}$ has length $> 520$, return $\mathrm{false}$; otherwise evaluate $E$ from $\mathrm{stack}$ with version $\mathrm{witnessV0}$ via $\mathrm{evalBytes}$; if that fails return $\mathrm{false}$; else return (resulting stack has length exactly $1$) $\land$ $\mathrm{topTrue}$ of it.

$\mathrm{evalBytes}(c, v, \mathrm{stack}, \text{script})$: if the script is longer than $10000$ bytes, fail; parse it into instructions (fail on a malformed push); then run the script interpreter $\mathrm{evalScript}$ with flags $\varphi = \mathrm{scriptFlagsOf}(c.\mathrm{flags})$ and oracle $\mathrm{legacyOracle}(\mathrm{sigFlagsOf}(c.\mathrm{flags}), c.\mathrm{tx}, c.n_{\mathrm{in}}, c.\mathrm{amount}, v, \text{script})$ — for $v = \mathrm{witnessV0}$ and script $W$ this is exactly $\omega$.

**The interpreter `evalScript`.** From the state (main stack, alt-stack $[\,]$, condition stack $\mathrm{vfExec} = [\,]$, $\mathrm{opCount} = 0$), one step per instruction; $\mathrm{some}$ of the final main stack if all steps succeed and $\mathrm{vfExec}$ is empty at the end, else $\mathrm{none}$. Push of $x$: fail if $|x| > 520$; push onto the main stack if all of $\mathrm{vfExec}$ is true (else unchanged); fail if $|\text{stack}| + |\text{alt}| > 1000$. Opcode $c'$: let $e$ = all of $\mathrm{vfExec}$ true; if $c' > \mathtt{0x60}$, fail if $\mathrm{opCount} + 1 > 201$ else increment; fail on the fifteen disabled opcodes; if $e$ or $\mathtt{0x63} \le c' \le \mathtt{0x68}$, apply $\mathrm{execOp}$ with flag $e$ then the size check; else unchanged apart from the size check. $\mathrm{execOp}$ for the opcodes of $W$: $\mathtt{0x4f}$/$\mathtt{0x51}$–$\mathtt{0x60}$ push $\mathrm{serialize}(c' - 80)$; `OP_IF` $\mathtt{0x63}$ with $e$ pops the top $x$ (fail if empty) and pushes $\mathrm{castToBool}(x)$ onto $\mathrm{vfExec}$, without $e$ pushes $\mathrm{false}$ onto $\mathrm{vfExec}$; `OP_ELSE` $\mathtt{0x67}$ negates the head of $\mathrm{vfExec}$ (fail if empty); `OP_ENDIF` $\mathtt{0x68}$ pops it (fail if empty); `OP_CHECKSEQUENCEVERIFY` $\mathtt{0xb2}$: unchanged if $\varphi.\mathrm{csv} = \mathrm{false}$, else fail on empty stack, let $x$ be the top (kept), fail if $|x| > 5$, let $n$ be its signed little-endian value, fail if $n < 0$, unchanged if $(\operatorname{toNat}(n) \mathbin{\&} 2^{31}) \ne 0$, else fail if $\omega.\mathrm{checkSequence}(n) = \mathrm{false}$, else unchanged; `OP_DROP` $\mathtt{0x75}$ pops (fail if empty); `OP_CHECKSIG` $\mathtt{0xac}$ needs $\mathrm{pk} :: \mathrm{sg} :: \mathrm{rest}$, then $\omega.\mathrm{checkSig}(\mathrm{sg}, \mathrm{pk})$: $\mathrm{none}$ fails, $\mathrm{some}\,\mathrm{ok}$ gives $\mathrm{boolBytes}(\mathrm{ok}) :: \mathrm{rest}$ ($[\mathtt{0x01}]$ for true, $[\,]$ for false). Parsing of a byte script: byte $\le \mathtt{0x4e}$ is a push whose length is the byte itself ($< \mathtt{0x4c}$), the next byte ($\mathtt{0x4c}$), the next two little-endian bytes ($\mathtt{0x4d}$) or the next four ($\mathtt{0x4e}$), failing if too few bytes follow; any byte $> \mathtt{0x4e}$ is an opcode.

**The concrete oracle $\omega$.** Its five hash components are the preamble's hash implementations; its lock-time component is the transaction lock-time check; and:

- $\omega.\mathrm{checkSequence}(s)$, for an integer $s$: let $\sigma$ be the $\mathrm{nSequence}$ of input $c.n_{\mathrm{in}}$ of $c.\mathrm{tx}$ (or $0$ if out of range). If $c.\mathrm{tx}.\mathrm{version} < 2$, $\mathrm{false}$; else if $\sigma \mathbin{\&} 2^{31} \ne 0$, $\mathrm{false}$; else with $M = 2^{22} \mid \mathtt{0xffff}$, $\tau = \sigma \mathbin{\&} M$, $\varsigma = \operatorname{toNat}(s) \mathbin{\&} M$: $\mathrm{false}$ unless ($\tau < 2^{22} \land \varsigma < 2^{22}$) or ($2^{22} \le \tau \land 2^{22} \le \varsigma$); then $\mathrm{false}$ if $\tau < \varsigma$; else $\mathrm{true}$.
- $\omega.\mathrm{checkSig}(\mathrm{sg}, \mathrm{pk})$, with signature flags $(\mathrm{dersig} = c.\mathrm{flags}.\mathrm{dersig}, \mathrm{false}, \mathrm{false}, \mathrm{false})$ and version $\mathrm{witnessV0}$ (so the script code is $W$ itself, with no signature deletion): the result is $\mathrm{none}$ exactly when $c.\mathrm{flags}.\mathrm{dersig} = \mathrm{true}$, $\mathrm{sg} \ne [\,]$ and $\mathrm{sg}$ fails the strict-DER-with-hash-type encoding test (length in $[9, 73]$, tag $\mathtt{0x30}$, consistent length bytes, two $\mathtt{0x02}$ integers each non-empty, non-negative and minimally padded, hash-type byte last); the public-key encoding test passes unconditionally since the strict-encoding and witness-pubkey-type flags are false. Otherwise it is $\mathrm{some}$ of the ECDSA verdict: $\mathrm{false}$ if $\mathrm{pk}$ is empty or its first byte does not announce its length ($\mathtt{0x02}/\mathtt{0x03} \mapsto 33$, $\mathtt{0x04}/\mathtt{0x06}/\mathtt{0x07} \mapsto 65$, anything else $\mapsto 0$); $\mathrm{false}$ if $\mathrm{sg} = [\,]$; otherwise, with hash type $=$ the last byte of $\mathrm{sg}$ and $\mathrm{sg}'$ $=$ $\mathrm{sg}$ without that byte, compute the BIP143-style digest of $(c.\mathrm{tx}, c.n_{\mathrm{in}}, W, \text{hash type}, c.\mathrm{amount})$ as defined in the preamble (double SHA-256 over version, hashed prevouts, hashed sequences, this input's outpoint, the length-prefixed script code $W$, the 8-byte amount, this input's sequence, hashed outputs, lock time and 4-byte hash type, with the usual ANYONECANPAY/SINGLE/NONE variations); return $\mathrm{false}$ if $c.\mathrm{amount} < 0$; else return the preamble's secp256k1 ECDSA verification of $\mathrm{sg}'$ (lax-DER parsed, $S$ normalized) against that digest reduced modulo the group order under the key $\mathrm{pk}$ (parsed as a compressed, uncompressed or hybrid point).

**The right-hand side's `SpendCondition`.** $\mathrm{SpendCondition}(\varphi, \omega, R, \delta, D, b, \mathrm{sig})$ is

$$
\big(\mathrm{castToBool}(b) = \mathrm{true} \land \omega.\mathrm{checkSig}(\mathrm{sig}, R) = \mathrm{some}\,\mathrm{true}\big)\ \lor\ \big(\mathrm{castToBool}(b) = \mathrm{false} \land \mathrm{CsvPasses}(\varphi, \omega, \delta) \land \omega.\mathrm{checkSig}(\mathrm{sig}, D) = \mathrm{some}\,\mathrm{true}\big),
$$

with $\mathrm{CsvPasses}(\varphi, \omega, \delta) \equiv \varphi.\mathrm{csv} = \mathrm{false} \lor \big(0 \le \delta \land ((\operatorname{toNat}(\delta) \mathbin{\&} 2^{31}) \ne 0 \lor \omega.\mathrm{checkSequence}(\delta) = \mathrm{true})\big)$, and $\mathrm{castToBool}(x)$: false for $[\,]$; for $[y]$ true iff $y \ne 0 \land y \ne \mathtt{0x80}$; for $y :: \mathrm{rest}$ with $\mathrm{rest} \ne [\,]$, true iff $y \ne 0 \lor \mathrm{castToBool}(\mathrm{rest})$.

**What is quantified and what is not.** The handler $\mathrm{tap}$ is arbitrary and the equivalence must hold for every one. The context $c$ is arbitrary except that its $\mathrm{witness}$ flag is on; the $\mathrm{p2sh}$, $\mathrm{taproot}$, $\mathrm{dersig}$, $\mathrm{cltv}$, $\mathrm{csv}$ and $\mathrm{nulldummy}$ flags are unconstrained, as are $c.\mathrm{tx}$ (which may have no inputs), $c.n_{\mathrm{in}}$ (possibly out of range) and $c.\mathrm{amount}$ (possibly negative). The witness prefix $\mathrm{ws}$ is an arbitrary list on the left; the right-hand side forces it to have exactly two elements, each of length at most $520$. The first conjunct on the right, $\mathrm{castToBool}(H) = \mathrm{true}$, is a condition on the digest of the witness script itself.
