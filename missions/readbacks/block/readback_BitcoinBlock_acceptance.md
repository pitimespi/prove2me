# Read-back: `BitcoinBlock.acceptance`

## Binders and hypotheses

- $S$ : a chain state (a list of serialized headers and a ledger, i.e. an association list from outpoints $\langle \text{hash bytes}, n\rangle$ to coins $\langle \text{output}, \text{height}, \text{isCoinbase}\rangle$).
- $b$ : a serialized block: a header (version $\in\mathbb{Z}$; previous-block hash, merkle root as byte lists; time, bits, nonce $\in \mathbb{N}$) and a list $b.\mathrm{vtx}$ of transactions (each: version $\in\mathbb{N}$, inputs, outputs, lock time $\in \mathbb{N}$).
- $\mathit{now} \in \mathbb{Z}$ : the local clock.
- Hypothesis $h_R$ : $\mathrm{Reachable}(S)$, the inductively defined predicate with two rules: the initial state $\langle [\mathrm{genesisHeader}], [\,]\rangle$ is reachable; and if $S_0$ is reachable and for some block $b_0$, clock $t_0$, state $S_1$ and undo list $u_0$ one has $\mathrm{validate}(S_0, b_0, t_0) = \mathrm{accept}(S_1, u_0)$, then $S_1$ is reachable.

## Conclusion

$$\mathrm{accepts}(S, b, \mathit{now}) \iff \mathrm{Valid}(S, b, \mathit{now}).$$

### Left side

$\mathrm{accepts}(S,b,\mathit{now})$ is the proposition $\exists S'\,\exists \mathit{undo},\ \mathrm{validate}(S,b,\mathit{now}) = \mathrm{accept}(S', \mathit{undo})$, where $\mathrm{validate}$ is computed as follows.

First $\mathrm{acceptHeader}(S, b.\mathrm{header}, \mathit{now})$ is evaluated: **invalid** if the proof-of-work check fails (hash of the header, read little-endian as a number, must be at most the compact target decoded from $b.\mathrm{header.bits} \bmod 2^{32}$, with the target required to be non-negative, non-zero, non-overflowing and at most $2^{224}-1$); else **missingPrev** if $b.\mathrm{header.prevBlock}$ differs from the hash of the tip header (the last header of $S$, or the genesis header if $S$ has none); else **invalid** if $b.\mathrm{header.bits} \bmod 2^{32}$ differs from the required work (the tip's bits unless $\mathrm{tipHeight}+1$ is a multiple of $2016$, in which case the retarget computed from the time of the header at index $\mathrm{tipHeight}-2015$, clamped at index $0$); else **invalid** if $b.\mathrm{header.time} \le \mathrm{mtp}(S)$ (the sorted median of the most recent at most $11$ header times, default $0$); else **futureTime** if $\mathit{now} + 7200 < b.\mathrm{header.time}$; else **invalid** if the version is below $2$, $3$ or $4$ while, respectively, $227931$, $363725$ or $388381 \le \mathrm{tipHeight}+1$; else **accept**.

If the header outcome is not accept, $\mathrm{validate}$ returns that same outcome. Otherwise: if $\mathrm{checkBlock}(b)$ is false, **invalid**; else if $\mathrm{contextualCheckBlock}(S, b)$ is false, **invalid**; else if $\mathrm{connectBlock}(S,b)$ is none, **invalid**; else, with $\mathrm{connectBlock}(S,b) = \mathrm{some}(u, \mathit{undo})$, the result is $\mathrm{accept}(\langle S.\mathrm{headers} \mathbin{+\!\!+} [b.\mathrm{header}],\ u\rangle, \mathit{undo})$.

- $\mathrm{checkBlock}(b)$ is the conjunction, in order: header PoW; the merkle root computed from the txids of $b.\mathrm{vtx}$ (pairwise double-SHA256 of concatenations, odd last element paired with itself, root $= 32$ zero bytes for no transactions) equals $b.\mathrm{header.merkleRoot}$; the merkle "mutated" flag (some aligned equal pair at some level) is false; $b.\mathrm{vtx} \ne [\,]$; $4\cdot|b.\mathrm{vtx}| \le 4\,000\,000$; $4\cdot|\text{serialization of } b \text{ without witnesses}| \le 4\,000\,000$; the first transaction (defaulting to the genesis coinbase if there is none) is a coinbase (exactly one input, whose prevout is 32 zero bytes with index $2^{32}-1$); no later transaction is a coinbase; every transaction passes $\mathrm{checkTransaction}$ (non-empty inputs and outputs; $4\cdot$ witness-stripped size $\le 4\,000\,000$; every output value in $[0, 2.1\cdot 10^{15}]$ with every running partial sum in that range; pairwise distinct input prevouts; for a coinbase the first input's scriptSig length is in $[2,100]$, otherwise no input prevout is null); and $4\cdot\sum_{tx}\mathrm{legacySigOpCount}(tx) \le 80\,000$.
- $\mathrm{contextualCheckBlock}(S,b)$: with $\mathit{height} = |S.\mathrm{headers}|$ and cutoff $=\mathrm{mtp}(S)$ if $419328 \le \mathrm{tipHeight}+1$ else $b.\mathrm{header.time}$: every transaction is final (lock time $0$, or lock time $<$ height resp. cutoff according to whether it is below $500\,000\,000$, or every input sequence $= 2^{32}-1$); if $227931 \le \mathrm{tipHeight}+1$ then the height script ($[0]$ for $0$, $[0x50+n]$ for $1\le n\le16$, else the canonical push of the script-number encoding) is a prefix of the first input's scriptSig of the first transaction (defaults: genesis coinbase, default input); the witness-malleation check with "expect" $= (481824 \le \mathrm{tipHeight}+1)$; and the block weight ($3\cdot$ stripped size $+$ full size) $\le 4\,000\,000$.
- $\mathrm{connectBlock}(S,b)$: if the header hash equals the genesis hash, $\mathrm{some}(S.\mathrm{utxo}, [\,])$; else if BIP30 is checked (not one of the two historical repeat blocks and the header at index $227931$ is absent or has a hash other than the BIP34 hash, or height $\ge 1983702$) and some output $\langle \mathrm{txid}(tx), o\rangle$ of some transaction already exists in the ledger, none; else run the transaction loop from $\langle S.\mathrm{utxo}, 0, 0, [\,]\rangle$ with the script flags for the height and the exception table, the height, the median-time-past function of $S$ (clamped to $\mathbb{N}$) and the lock-time flags ($1$ once height $\ge 419328$, else $0$); none propagates; otherwise none if the first transaction's total output exceeds accumulated fees plus the subsidy ($50\cdot10^8$ halved per $210\,000$ blocks, $0$ beyond $64$ halvings), else $\mathrm{some}(\text{final ledger}, \text{final undo})$. The loop, per transaction: for a coinbase, no input checks; otherwise $\mathrm{checkTxInputs}$ must give a fee, the new fee total must be in money range, and BIP68 must hold; then the cumulative sigop cost must not exceed $80\,000$; then (non-coinbase) every input script must verify; then the ledger is updated (inputs spent unless coinbase, spendable outputs added at the height).

### Right side

$\mathrm{Valid}(S,b,\mathit{now})$ is the conjunction $\mathrm{HeaderSpec}(S, b.\mathrm{header}, \mathit{now}) \wedge \mathrm{BlockSpec}(b) \wedge \mathrm{ContextSpec}(S,b) \wedge \mathrm{LedgerSpec}(S,b)$:

- $\mathrm{HeaderSpec}$: the compact word $b.\mathrm{header.bits} \bmod 2^{32}$ is not negative, does not overflow, its exact (untruncated) target is $>0$ and $\le 2^{224}-1$, and the header hash value is $\le$ that target; $b.\mathrm{header.prevBlock} = \mathrm{tipHash}(S)$; the compact word equals $\mathrm{requiredBits}(S)$; $\mathrm{mtp}(S) < b.\mathrm{header.time} \le \mathit{now} + 7200$; and the version is not outdated (negation of the same three-way disjunction as above).
- $\mathrm{BlockSpec}$: $b.\mathrm{vtx}\ne[\,]$; merkle root equal and not mutated; the two $4\cdot\!$ size bounds; every transaction among the first one is a coinbase and none of the rest is; every transaction satisfies $\mathrm{TxSpec}$ (non-empty inputs/outputs, stripped size bound, each output value in $[0,\mathrm{MAX\_MONEY}]$ and total output $\le \mathrm{MAX\_MONEY}$, distinct prevouts, coinbase $\Rightarrow$ every input scriptSig length in $[2,100]$, non-coinbase $\Rightarrow$ no null prevout); and the legacy sigop bound.
- $\mathrm{ContextSpec}$: same finality, witness-malleation and weight clauses as $\mathrm{contextualCheckBlock}$, but the height-script clause is "if BIP34 is active then for every transaction among the first one and every input among its first one, the height script is a prefix of its scriptSig" (vacuous when there is no transaction or no input).
- $\mathrm{LedgerSpec}$: the header hash equals the genesis hash, **or** all of: if BIP30 is checked then no output $\langle\mathrm{txid}(tx), o\rangle$ with $o < |tx.\mathrm{vout}|$ is present in $S.\mathrm{utxo}$; $\mathrm{TxsSpec}$ holds from $(S.\mathrm{utxo}, 0, 0)$ (each non-coinbase satisfies $\mathrm{TxInputsSpec}$ — existing, mature, in-range coins; total input $\le \mathrm{MAX\_MONEY}$; outputs $\le$ inputs; BIP68 specification form; every input script verifies — and the running fee total $\le \mathrm{MAX\_MONEY}$; the running sigop cost $\le 80\,000$; recursively on the updated ledger); and for every transaction among the first one, its total output $\le$ the block's total fees (against the running ledger) plus the specification subsidy $\lfloor 50\cdot10^8 / 2^{\lfloor \mathit{height}/210000\rfloor}\rfloor$.

## Edge cases silently included

$h_R$ is the only hypothesis and is used on both sides only as stated; empty $b.\mathrm{vtx}$ (defaults to the genesis coinbase in several Boolean checks, vacuous quantifiers in the specification); a block whose header hash is the genesis hash (both sides short-circuit the ledger part); unbounded naturals for time/bits/version reduced modulo $2^{32}$ where converted; natural subtraction in $\mathrm{tipHeight}$, in the retarget index and in coin maturity; $\mathrm{accessCoin}$ defaulting to a dummy coin of value $-1$ in the specification's $\mathrm{valueIn}$; the $\mathrm{mtp}$ function clamped to $\mathbb{N}$.
