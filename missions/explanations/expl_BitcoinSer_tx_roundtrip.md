Split on whether the extended format is used, i.e. on `aw && tx.hasWitness`.

*Basic format* (`serTx_basic`): the bytes are `version vin vout nLockTime`. `readTx` reads the version (`readLE_leBytes`), then `vin` by `readList_vin` (a vector round-trip: CompactSize length within `MAX_SIZE`, then `readN` over `flatMap`, each input by `readTxIn_ser`, which yields the input with an empty witness). The dummy test `vin0.isEmpty && aw` is false: either `aw = false`, or `aw = true` and the hypothesis gives a non-empty `vin`. So `vout` is read (`readList_vout`, each output by `readTxOut_ser` with the signed amount), `flags = 0`, the witness branch and the unknown-flag test are skipped, and `nLockTime` is read. The result is `tx` with witnesses cleared, which is `tx.stripWitness` — and equals `tx` itself when `aw = true`, since then `hasWitness = false` means every witness was already empty (`strip_of_no_witness`).

*Extended format* (`serTx_ext`, `aw = true` and `hasWitness`): the bytes are `version 0x00 0x01 vin vout witnesses nLockTime`. The reader's first `readList` consumes the `0x00` as an empty vector (`hdummy`); `vin0 = []` and `aw` trigger the dummy branch, the flag byte `0x01` is non-zero, so `vin` and `vout` are read; bit $1$ of the flags is set, so `readN (readList readBytes)` reads one witness stack per input (`readWitnesses_ser`, by induction over the inputs), `attachWitness` restores them onto the stripped inputs (`attachWitness_map`), the "superfluous witness" test passes because `hasWitness`, the flags drop to $0$, and `nLockTime` is read. The result is exactly `tx`.
