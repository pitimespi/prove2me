Four cases on the width class of $n$. Below $253$ the writer emits the single byte $n$ and the reader returns it (`ser8_toNat`). Otherwise the marker byte $253$, $254$ or $255$ is read, the reader calls `readLE` on $2$, $4$ or $8$ bytes, which returns $n$ by `readLE_leBytes` (the width bound holds in each class: $n \le \mathtt{0xffff}$, $\le \mathtt{0xffffffff}$, $< 2^{64}$), and the non-canonical test fails since $n$ is at least $253$, $2^{16}$ or $2^{32}$ respectively. The proof is written once for either range-check mode (`compactSize_roundtrip_gen`), with the range test discharged by the hypothesis $n \le \mathrm{MAX\_SIZE}$ when the mode is on; the public statement is the unchecked mode.
