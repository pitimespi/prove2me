Induction over the chain generalizing the state. The reversed zip of the chain splits as the reversed tail followed by the first block, so `disconnectChain_append` separates the two; the induction hypothesis (the tail's state is reachable by `Reachable.step`, and `FreshChain` continues) undoes the tail to a state equivalent to the state after the first block; `disconnect_connect_equiv` then undoes the first block from that equivalent ledger. `apply_spec` gives the headers after the block as the old headers with the header appended, so the tip height is the old next height and `dropLast` restores the old headers.
