Seven parts. `setInitialState`: the accepted state becomes `s`, of term 0, which is at most any term (`omega`), and the current term is untouched. `handleStartJoin`: by `handleStartJoin_spec` the accepted state is unchanged and the new term exceeds the old one, which is at least the accepted term (`omega`). `handleJoin`, `handleClientValue`, `handlePublishResponse`: unfold, discard each rejection branch (`split at h` then `cases h`); in the accepting branches the result differs from `cs` only in transient fields, so `hcs` and `rfl` close the goal. `handlePublishRequest`: by `handlePublishRequest_spec` the new accepted state's term is the current term, which is unchanged. `handleCommit`: by `handleCommit_spec` the result is `cs` with an updated accepted state of the same term.
