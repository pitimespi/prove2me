Obtain the invariant from `reachable_inv` and use `accepted_realizes` at the eligible node. A never-bootstrapped node has the empty configuration; a bootstrap state has a bootstrap configuration. If the accepted state is realized by a publication with the node's last committed configuration equal to the publication's last committed one, `inv_pub_lcc` says that this is a bootstrap configuration or the last accepted configuration of a committed publication; if it is equal to the publication's last accepted configuration with the key committed, the publication itself is the witness.
