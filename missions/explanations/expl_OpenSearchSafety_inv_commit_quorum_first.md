`commit_quorum` gives the publication `C` and responders `A`. If `A` is a quorum of `C`'s last committed configuration, that configuration is a bootstrap configuration by `inv_root_lcc` (the key has no committed proper ancestor). In the D1 case the committed parent of `C` is a proper ancestor of the committed key, which the hypothesis forces to be the key itself, while `pub_wf` makes its version smaller: a contradiction.
