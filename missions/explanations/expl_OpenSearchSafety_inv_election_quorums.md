First derive antisymmetry of descent and that a committed ancestor of a base of term below `t` has term below `t`. Apply `inv_pivot` to both bases. If both have committed pivots, `inv_elc` applied to each record with the other's pivot puts each pivot below the other base, so maximality makes each pivot an ancestor of the other; antisymmetry gives the same key, `pub_unique` the same publication, and both voter lists are quorums of its last accepted configuration (it is `x` or `y` of each record), so `quorum_intersect` gives a common voter. If exactly one base has a committed pivot, `inv_elc` puts that pivot below the other base, contradicting the absence of committed ancestors there. If neither has, both `x₁` and `x₂` are bootstrap configurations, and `P.InitCompatible` applies to the voter lists, which consist of eligible nodes by `BaseVoters`.
