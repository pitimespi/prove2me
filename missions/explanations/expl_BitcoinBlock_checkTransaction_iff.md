`outputsLoop_iff` (induction on the outputs with `0 ≤ acc ≤ MAX_MONEY`): the loop succeeds iff every value is in `[0, MAX_MONEY]` and `acc + Σ values ≤ MAX_MONEY`, using `sumValues_nonneg` for the failing-range case. The remaining Boolean conjuncts (`isEmpty`, the size, `Nodup`, and the coinbase `if`) are converted with `simp`; the coinbase branch destructs `vin = [i]` from `isCoinBase`, so `headD` is the unique input.
