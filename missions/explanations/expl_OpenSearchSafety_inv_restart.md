The node's new state is the constructor over its current term and `s'`, so its transient state is reset. `RestartState` gives either the same accepted term, version and configurations, or a node that never joined a cluster coming back with a term-0 state and empty configurations (`hkey`). Winning only shrinks. The fields: the node's transient facts hold trivially; `term_le` and `accepted_realizes` hold by `hkey` (the second case by the first disjunct of `accepted_realizes`); `response_le` holds in the first case unchanged, and in the second case vacuously, since a node whose accepted term was 0 sent no publish response (its response would have a term of at least 1, `response_published` and `pub_wf`); `pub_source_term` holds for the node because it has not started a join since the restart; everything else carries over, the messages being unchanged.
