`commit_quorum` gives the publication `C` of the committed key and responders `A`, eligible, that are a quorum of `C`'s last accepted configuration and either of its last committed configuration or, in the D1 case, the parent of `C` is committed and is a publication with the same last accepted configuration. In the first case `inv_lineage` from `D` to `C` says that `D`'s last accepted configuration is `C`'s last committed or last accepted configuration, and `A` is a quorum of both. In the D1 case the committed parent lies between `D` and `C` (`inv_descends_parent` and the parent link), so by the hypothesis it is `D`'s key (it cannot be `C`'s key, whose version is larger, `pub_wf`); `pub_unique` identifies the parent's publication with `D`, so `D`'s last accepted configuration is `C`'s, of which `A` is a quorum.
