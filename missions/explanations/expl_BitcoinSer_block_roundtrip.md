Unfold `readBlock` and `serBlock`: the header round-trips by `header_roundtrip`; the transaction vector by `readList_vtx`, the vector round-trip specialized to `readTx aw`/`serTx aw`: the length is within `MAX_SIZE`, and each transaction round-trips by `tx_roundtrip` — its side condition (`aw = true → vin ≠ []`) follows from the block well-formedness clause "an input or a witness", since a witness implies an input. The map `(if aw then id else stripWitness)` is what `tx_roundtrip` returns element-wise.
