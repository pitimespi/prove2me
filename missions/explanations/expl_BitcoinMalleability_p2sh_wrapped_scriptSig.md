A P2SH script (23 bytes starting `0xa9`) is not a witness program, so `verifyScript` takes the P2SH branch: the scriptSig evaluation must succeed with a non-empty stack `redeem :: rest`, the scriptPubKey evaluation must leave a true top, `isPushOnly scriptSig` must hold, the redeem script must evaluate to a true top, and then — with `WITNESS` set — if `redeem` is not a witness program a non-empty witness fails (`SCRIPT_ERR_WITNESS_UNEXPECTED`), while if it is one the test `scriptSig ≠ pushBytes redeem` fails (`SCRIPT_ERR_WITNESS_MALLEATED_P2SH`).
